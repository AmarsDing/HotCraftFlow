# 风格 B：DOTS / GPT-6.1 —— Agent 节点图谱 · 作战室（Mission Control）

> 适用场景：Agent 执行轨迹观测、节点关系图谱、AI 作战室大屏、"机器干活、你签字"式审批界面。
> 核心气质：终端驾驶舱 + 数据密度崇拜——一屏 20+ 数据点、"毛球"图谱（密度即智力感）、语义色状态机。
> 内含三个子风格：① 深绿图谱 ② 深红作战室 ③ 编辑部排版 NODE MAP。

## 1. 设计思路

- **认知锚是"毛球"**：节点极少、边极多（20 节点 / 350 边），灰网为主、彩束点缀，密度本身传达"智能"。
- **语义色 = 状态机，零例外**：绿=正常/低成本/进行中，红=门禁/阻塞/高负载，琥珀=等待/人工介入，青=流动/激活。
- **红框是最强识别特征**：作战室整块媒体区用红色描边容器（左右 16px、底部 18px `#b81027`）。
- **填充条内嵌标签**：参数条长度∝数值，兼任条形图，省纵向空间。
- **不同区域用不同图形语言**：主场景折线、ACCOUNT 星座网络、路由器辐射网络，各归其位。
- **AWAIT USER 金门**：人工审批点用金色呼吸微光突出——叙事核心"你签字"。

## 3. 字体排版

- **全数字/指标/代码/日志统一等宽**：`"JetBrains Mono", ui-monospace, monospace`（参照 IBM Plex Mono / Berkeley Mono）+ 全局 `font-variant-numeric: tabular-nums`。
- 作战室标题：压缩粗体无衬线（D-DIN/Oswald 风，白 800，可用 `transform:scaleY(1.12)` 逼近压缩感）。
- NODE MAP 标题可用 serif 制造编辑部气质：`"Newsreader", Georgia` 30px / 1.12 / ls -.01em。
- 字号阶梯：微标签 8–10.5px 大写 + ls `0.08–0.12em`；数值 10–13px 等宽；代码 10px；节点标题 11px；角色名 15.5px 特粗；卡内主数值 21px 特粗右对齐；脚注 8.5px `#565e66` 大写；大计数器 40–64px 800。
- 深色下文字最小 10px、对比度 ≥ 4.5:1。

## 4. 布局

- **图谱**：grid rows `220px 910px 135px 385px`（指标/画布/字幕/dock）；dock 三列 `520px 490px 310px`，列间 `gap:1px` 发丝分割；时间轴贴画布顶缘内侧；分段控件绝对定位 `top:14px; left:50%` 悬浮画布顶部。
- **作战室**：62px 红色标题带 → Agent 卡区 244px（8 张同构卡 4×2，gap 8px）→ 主场景 740px（占容器 41%，最大）→ 面板行 1（222px）→ 面板行 2（~500px）；X 帖子卡片用 `margin-top:-126px; z-index:6` 叠压容器下缘。
- **NODE MAP**：8 列混合栅格 `19.4% 1fr 14.4% 1fr 9.8% 10.8% 11% 13.6%`（6 车道夹 2 条 SVG 连线走廊）。
- 通则：面板 padding 8–12px、圆角 2–6px（卡片 14px / 胶囊 999px）、1px 边框或 `gap:1px` 发丝分割。
- 响应式策略：**等比还原固定构图**（如 1320×2868 竖屏），不做断点，仅 resize/scroll 防抖 120–200ms 重算连线。约 470 个 `<path>` 仍可 60fps。

## 5. 核心组件配方

- **节点卡** 220×90px r=6：4–6px 彩头（按类型着色）+ 11px 等宽标题 + kv 行（值右对齐 + 2px 迷你条）+ 四边连接埠。
- **面板四段式**：微标签（大写小字）/ 状态点 / 主数值 / 脚注——所有面板统一此骨架。
- **参数填充条**：青绿渐变条内嵌标签、条长∝值、Missing 态琥珀底 + 0.4s 抖动。
- **Agent 卡五行结构**：22×22 图标（r=7px、`0 0 12px` 同色辉光）/ 角色名 + DOT 编号 / 状态行 / 主数值（角色色）/ 3px 进度条（38%↔86% 往复 2.4s）/ 脚注。
- **分段控件**：激活 = 薄荷青底深字。
- **阶段字幕**：4px 彩竖条 + 大字幕 + 黄色副标题。
- **代码面板**：等宽 10px + `12 l/s` 标注 + `▍` 块光标 `1s steps(2)`。
- **RUN LOG**：彩点前缀 + 滚动日志。
- **AWAIT USER 徽章**：金底 `#bf9442` 深字 + 呼吸微光。
- **K 线块**：26 根涨绿跌红 + 1px 影线 + 4 条水平网格；右侧配 112×46px sparkline。
- **NODE MAP 专属**：SOURCE 卡左缘 4px accent bar（::before top:9px bottom:9px）、右缘 5px 外凸连接点（`0 0 6px` 辉光）、时间轴菱形事件点（rotate45）+ 红 now 胶囊（`0 0 14px` 辉光）+ 1×18px 引出线。
- **泳道芯片**：面板顶底各一行胶囊 + 彩点，夹住中间内容。

## 6. 动效

- 节点弹入 `scale .9→1` ~200ms `cubic-bezier(0.34,1.56,0.64,1)`（带回弹）；星座节点 `i×0.07s` 阶梯 pop（`.6→1.08→1`），边晚 0.5s。
- 计数器 rAF + easeOutExpo/easeOutQuart；变化时 `scale(1.04)` 120ms 脉冲；余额类数字先快后慢定格——**"有终点的计数"比无限滚动更像真实产品**。
- 流动光带 / router 光点：周期 2–4s 线性循环，逐条延迟 0.18s。
- 打字机 10–14 行/s；日志 ~100ms/条；idle 浮动 ±2px 3s ease-in-out；live 脉冲 `opacity 1↔.4` 1.6s。
- 视图/字幕切换：双图层交叉 150ms；**硬切 0 过渡反而更真实**（录屏感）。
- 路径绘制动画必须 `getTotalLength()` 动态取长，1300ms ease-in-out。
- 热图 0%绿→50%琥珀→100%红 插值；进度 flash `brightness(1.9)` 320ms。
- 陷阱：多帧计数器需"代数令牌"中断整条 setTimeout 链；`prefers-reduced-motion` 降级。
- hover 语义弱（自动播放观测盘），**激活态/状态色才是主要反馈**。

## 7. 特色技法

1. **流动光带（dashoffset 铁律）**：位移量必须等于 dasharray 总和，否则接缝跳变——
   ```css
   .edge-flow { stroke-dasharray: 6 220; animation: flow linear infinite;
                filter: drop-shadow(0 0 4px var(--amber)); }
   @keyframes flow { to { stroke-dashoffset: -226; } }  /* 6+220=226 */
   ```
2. **毛球四层法**（最决定成败，绘序即层级）：
   - 第 1 层：幽灵边 15–20 组 × 3 条，spread ±110px，alpha **.06**；
   - 第 2 层：~~拓扑相邻~~**随机**节点对约 420 条长贝塞尔，spread ±190px，`rgba(216,234,226,.10–.34)`，0.8/1.3px；
   - 第 3 层：主干 bundle 4–12 条，spread ±6px；
   - 第 4 层：彩色粗束 12–14 组 × 3 条，3px，`opacity .72` + `drop-shadow(0 0 7px)`，限定四色。
   - **彩色严格限少数**：>20 组就变成"彩色面条"。
3. **同色辉光体系**：连接点 `0 0 6px`、图标 `0 0 12px`、在线点 `0 0 8px`、now 胶囊 `0 0 14px`——辉光颜色永远等于元素本色。
4. **星座/辐射网络**：预设坐标 + pop 回弹 + 中心圆角矩形框 + 2 圈椭圆轨道（一实一虚）+ 卫星 + `getPointAtLength()` 沿线光点。
5. **发丝分割**：`gap:1px` + 背景色（比 border 更锐利）。
6. **叠压式 chrome**：负 margin + 半透明浮层透出下层 = 截图级真实感纵深。
7. **左缘 accent bar + color-mix/rgba 派生**全套深浅变体。

## 8. 可复用模式

面板四段式 · 一实体一色 `--accent` 级联派生 · 语义色状态机零例外 · 数字三件套（等宽 + tabular-nums + easeOut 计数器 + scale 脉冲）· 填充条兼任条形图 · **密度靠层不靠块**（雾 .06 → 网 .10–.34 → 主干 → 霓虹 .72+glow）· 自动播放叙事（仅 transform/opacity 保 60fps）· 彩点 + 同色辉光 = 全局统一的"端口"语言 · AI 观测屏语义（NODES/EDGES/COST 指标流、DOT 0N 编号、AWAIT USER 金门）· 硬切 + 叠压造真实感。
