## 一、十条设计铁律（四套系统的最大公约数）

1. **近黑不是纯黑。** 底色用 `#0A0E10` / `#18191D` 这类带一点青灰或中性倾向的近黑；纯黑会"立刻变廉价"，且让辉光和发丝线失去层次。
2. **层级靠明度 + 发丝线，不靠投影。** 背景做 3–4 档明度阶梯（page → card → elev → inset），分区用 `1px rgba(255,255,255,.05–.08)` 发丝线；投影只留给真正浮起的弹窗/浮卡。
3. **一色一语义，零例外。** 语义色是状态机：绿=成功/收入/正常，红=错误/阻塞，琥珀=等待/需人工决策，青=激活/流动。整个系统 5–8 个高饱和强调色，每个颜色只服务一种含义，用户才能"读色知意"。
4. **强调色三态派生公式：背景 12% / 描边 35–45% / 文字 100%。** 暗底上彩色块不发脏的关键就是这个比例；用 `color-mix(in srgb, var(--x) 12%, transparent)` 动态派生，不要手调新颜色。
5. **所有数字必须 `tabular-nums`。** 等宽数字 + 定宽列是"数字在跳但不抖"的唯一原因。数字/指标/代码/日志一律等宽字体。
6. **密度靠小字号 + 大行高 + 分割线，不靠留白。** 终端主力字号 12px、微标签 9.5px；列表用行间 1px 线代替卡片间距；9.5px/600/大写/字距 +0.14em 的区块标签是高级感的直接来源。
7. **动态感来自数据，不来自装饰。** 状态点呼吸、数字 lerp、连线流动——屏幕"活着"是因为数据在更新。纯装饰性大动画（入场飞入、过度弹跳）在这类界面里是廉价感来源。
8. **动效只用 transform / opacity / filter，时长令牌化。** 微交互 120–180ms、内容增删 220–300ms、视图切换 800–900ms、装饰循环 2–14s；缓动两条全局复用（果断 `.2,.9,.2,1` 与柔和 `.4,0,.2,1`）；必须支持 reduced-motion 降级。
9. **辉光同色且克制。** `box-shadow/text-shadow` 发光颜色永远等于元素本色（连接点 `0 0 6px`、图标 `0 0 12px`、关键 KPI `0 0 22px`），只点亮真正关键的少数元素；全屏霓虹 = 彩色面条。辉光配额按稳态计，审批/告警等事件态豁免，事件消散即熄灭。
10. **金融/审批界面给用户"锚点叙事"。** AWAIT USER 金门、待审批点线边框、底部服务器时间 + 连接状态点——让"机器干活、你签字"的权责关系一眼可见。

## 二、配色方法论

### 配色决策流
1. **定底色**：近黑略带倾向（青灰 `#0A0E10` / 中灰 `#18191D` / 深绿 `#0c1514` / 深红 `#080d13`）——底色倾向决定整屏气质。
2. **定交互主色（accent）**：全系统唯一的"可操作"信号色（青 `#0CA890`/`#41D2F3`、薄荷 `#afe0d9`），选中/链接/激活/Tab 全用它。
3. **定语义色**：按产品状态集配 4–6 个；金融场景涨跌色与交互主色**双轨分离**（涨跌只表数据方向，Buy/Sell 之外不大面积填充）。
4. **派生不靠手调**：背景态 12% alpha、描边态 35–45% alpha、hover +.04 alpha——全部 color-mix 派生。
5. **氛围层**：大 radial-gradient 雾光（2–3 团、alpha .05–.10、强调色系）叠在页面底，少了这层页面会"死黑"；再叠一层 24px 点阵/网格 `rgba(255,255,255,.02)` 增加"仪器感"。

### 关键透明度速查
| 用途 | 值 |
|---|---|
| 发丝分隔线 | rgba(255,255,255,.05–.08) |
| hover 背景 | rgba(255,255,255,.04) |
| 强调色背景态 | 色 × 12%（琥珀 10%） |
| 强调色描边态 | 色 × 35–45% |
| 图谱幽灵边/底纹 | 色 × .06 / 白 × .02–.03 |
| 预置暗态行 | opacity .32 |
| 辉光 | 同色 box-shadow，blur 6–22px |

## 三、字体排版方法论

- **双字体栈**：UI 无衬线（Inter / Space Grotesk + PingFang/YaHei 中文回退）+ 等宽（JetBrains Mono / IBM Plex Mono）。要"编辑部气质"的标题可换衬线（Newsreader）；要"军工感"标题用压缩粗体（Oswald/D-DIN，可 `scaleY(1.12)` 模拟）。
- **字号阶梯**（四套系统收敛值）：9.5 微标签 · 10 元信息/日志 · **12 正文（终端主力）** · 13 行标题 · 15 模块标题/行数值 · 20–22 价格/统计 · 28–34 KPI 大数字。
- **字重**：标签 600、正文 500、数值/价格 700；数字永远比同级文字重一档。
- **区块标签公式**：`9.5px / 600 / uppercase / letter-spacing:.14em / text-3 色`。
- **数字三件套**：`tabular-nums` + mono 字体 + 右对齐；KPI 大数字可加持同色 text-shadow 发光（`0 0 22px 色×.35`）。

## 四、布局与密度方法论

- **骨架三选一**：① 三栏工作区（`0.9fr 1.75fr 1.35fr` 式非等分）② 终端五区（顶栏三行 + 40px 图标 rail + 三栏主区 + 底部状态栏 + 220px 交易/输出区）③ 大图谱画布 + dock 面板行。
- **间距 4pt**：4/8/12/16/20/24px；面板 padding 12–16px；模块间距 8–14px。
- **圆角语言**：面板/行小圆角（2–8px）、按钮 8px、芯片胶囊 999px、只有主容器卡可 14–18px。金融终端可全系统 ≤10px 保持严肃。
- **列间分割优先用发丝线**：`.row + .row{border-top:1px solid rgba(255,255,255,.05)}` 或 grid `gap:1px` + 底色（比 border 更锐利）。
- **列表行的灵魂**：左侧 2–3px 分类色竖条 `border-left:3px solid var(--accent)`；行内"状态点 + 名称 → 条 → 右值"单排流。
- **构图两类**：对外演示的驾驶舱，固定构图等比缩放优于响应式断点；若是窄屏产品（592px 三栏），断点必须压到 380px 以下。

## 五、动效方法论

| 场景 | 参数 |
|---|---|
| hover/反馈 | 120–180ms，`brightness(1.08)` 或背景 +.04 alpha |
| 行/元素增删 | 220–300ms、`opacity+translateY(-6px)→0` |
| 弹窗 | 180ms `opacity+scale(.96→1)`，无遮罩非模态优先；`active` 态 `scale(.97)` |
| 视图切换 | 800–900ms，`scale(1.035)+blur(7px)` 形变（enter），退出 `scale(.965)+blur(7px)` |
| 数字更新 | lerp `cur+=(target-cur)*0.12`，全局单 rAF（离散状态计数 snap 直写或 0.35+ 快系数）；或 600ms 背景闪烁（金融铁律：**闪背景不闪字**） |
| 状态点/在线 | 呼吸 `opacity .55↔1` 2s alternate |
| 流动连线 | dashoffset 位移量 = dasharray 总和；装饰环 `spin 14s linear` |

- 弹窗/抽屉出现时主内容 `scale(.97)+brightness(.85)` 同步退后，一次到位。
- 一切会高频触发的位移动画改成 `transform:scaleX()`，禁动 width/left/top。
- **叙事编排**：用事件总线让一个业务事件同步驱动 弹窗→列表→日志→数字 四件套，这是"产品感" vs "demo 感"的分水岭。

## 六、通用组件配方速查

- **KPI 大数字**：mono 28–34px/700 + tabular-nums + 同色 .35 text-shadow + 下方 9.5px 大写标签；数值在上标签在下。
- **面板四段式**：微标签（大写）→ 状态点 → 主数值 → 8.5px 脚注，所有面板统一此骨架。
- **Chip/徽章**：26px 高胶囊 + `色×.12` 底 + `色×.35` 描边 + 原色文字；待办态末尾加 `> YOU` 高亮责任人。
- **待审批态**：`border:1px dotted 琥珀×.55` + 琥珀×.10 底 + 琥珀小字 `pending your OK`——点线 = "等人类"。
- **选中态三套路**：描边胶囊（accent 色边 + accent .08 底）/ 2px 下划线 / 2–3px 侧竖条；一个产品选一套用到底。
- **弹窗**：`rgba(12,12,24,.96) + backdrop-filter:blur(8px)` + 语义辉光；**按钮默认幽灵态，仅 hover 翻成实心亮底深字**。
- **日志**：fixed 高度、底部插入、旧行 150ms 淡出、行间 1px .04 线、时间戳最暗、关键数字 `<b>` 提亮。
- **进度/负载条**：4px 高、r=2、底白 .07、**不撑满**（max-width 78px 更有仪表感）、scaleX 驱动。
- **网络/拓扑图**：底轨 `白×.05–.10`、数据流用彩色点链（r≈2px、间距 6px、同色 glow）而非灰实线；密度分层绘序：雾 .06 → 网 .10–.34 → 主干 → 霓虹 .72+glow。

## 七、交付前自查清单

- [ ] 底色不是纯黑；背景至少 3 档明度；分区用了发丝线而不是全靠间距或投影
- [ ] 每个强调色只服务一种语义；彩色背景块全部 = 原色 × 12% alpha
- [ ] 所有数字 `tabular-nums` 且等宽字体；负值 `-` 前缀 + 语义色
- [ ] 有 9.5px 大写字距区块标签；层级由"字号+明度"区分而非全靠加粗
- [ ] 动画只动 transform/opacity/filter；时长来自令牌表；reduced-motion 有降级
- [ ] 数据更新动效是 lerp 或 600ms 背景闪烁，不是颜色跳变
- [ ] 辉光颜色 = 元素本色，且全屏发光元素可数（≤7 处，按稳态计，审批/告警事件态豁免）
- [ ] 有"实时信任锚点"（时钟/连接状态/数据更新时间）
- [ ] hover 有反馈（brightness 或背景 +.04）；`active` 有 `scale(.97)` 类按压感
- [ ] 弹窗非模态不锁滚动；无 `overflow:hidden` 误裁浮层；窄栏 meta `nowrap+ellipsis`

## 使用方式

1. 按"风格选型表"选变体，打开对应 references 文件取完整 token、组件与技法细节。
2. 以 `assets/tokens-base.css` 起步，改 `--accent` 与底色倾向定基调，再按变体替换语义色组。
3. 先搭骨架（铁律 1/2/6），再灌数据动效（铁律 5/7/8），最后点亮辉光与叙事编排（铁律 9/10）。
