# SPIDERORB // RESEARCH BOT — 前端复刻 Demo 验证报告

> **验证目的**：检验 `SPIDERORB-UI复刻实现指南.md` 是否具备足够指导性，能让前端（或 AI）据此复刻出视频中的 UI 效果。
> **验证方式**：按文档规范实现单文件 HTML Demo → 无头 Chromium 以 1320×2868 视口截图 → 与原视频帧做**区块位置、色彩、动效**三重机器比对。
> **结论**：✅ **文档可用，复刻度约 90%**。11 项动效断言 11/11 通过，区块位置偏差普遍 <2%，全图平均像素色差 6.1%。

## 六、复刻过程中发现并修复的 5 个问题

这些是"文档 → 代码"落地时真实踩到的坑，也反向证明了文档在哪些地方还不够细：

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 计数器千分位逗号丢失 | `initOdometer` 按字符建格时未处理 `,`（只在 set 时处理） | `build()` 分支生成 `.od-comma` 独立格 |
| 2 | 仪表文字压在弧线上 | 弧半径 38 + 文字 y=46/64 重叠 | 弧加粗至 9，文字下移到 y=72/86，下移出弧内 |
| 3 | **决策栈与智能体区块完全空白** | `every()` 立即执行一次 → 回调内 `$("#barSignal").nextElementSibling` 为 `null` 抛异常 → 后续初始化代码全部中断 | 用 `id` 显式定位数值节点；`every()` 改为不立即执行 |
| 4 | reduced-motion 下 ORB 全黑 | ResizeObserver 异步回调二次 `resize()` 重置 canvas 宽高清空画面，而该模式无 rAF 重绘 | `resize()` 后主动 `draw()` |
| 5 | reduced-motion 下整页脚本崩溃 | `const p1,p2` 声明在 `resize()` 调用之后，同步 `draw()` 触发 TDZ 报错 | 变量声明提前到 `draw()` 定义之前 |

> **问题 3 值得注意**：它不是"样式不像"，而是**静默的功能性缺失**——页面看起来正常，但两个区块是空的。若非写了断言脚本逐项数元素，肉眼很可能漏掉。这也说明：**做 UI 复刻必须用断言脚本验证，不能只靠截图目视。**

## 七、对文档的评估与补充建议

### 文档做得好的地方（可直接指导落地）
1. **色值实测** —— 直接抄就能用，无需调色。
2. **区块百分比坐标** —— 是本次能把 ORB 区占比做到 36% vs 38% 的关键。
3. **动效参数量化**（计数器 1329→1333/5.9s、日志间隔、粒子 180 个、布朗漂移 + 呼吸 + 距离连线）—— 直接对应到 JS 常量。
4. **语义色映射规则**（绿=SAVE、红=BLOCK、金=QUANT）—— 让配色有逻辑而非随机。

### 文档缺失 / 需补充的点
| 补充项 | 说明 |
|---|---|
| **字体落地方案** | 文档只说"等宽像素字体"，未指明可用字体。实际用了 `Share Tech Mono`（正文）+ `Silkscreen`（标题/像素字），且 Google Fonts 的 latin 子集**不含** `◆▲★` 等符号 → 这些符号必须用 CSS 伪元素/图形绘制，否则渲染成豆腐块。 |
| **响应式降级规则** | 文档未定义窄屏行为。本次自行补充：`@media (max-width:1100px)` 三栏转单栏。 |
| **reduced-motion 降级** | 文档未提及无障碍。本次补充：冻结所有定时器、Canvas 绘制静态帧。 |
| **`every()` 语义陷阱** | 文档给的定时器写法"立即执行一次"会放大初始化异常的影响，建议明确"初始化与定时更新分离"。 |
| **Canvas 与 ResizeObserver 的清空竞态** | 任何自适应 Canvas 都要在 `resize()` 后主动重绘一帧。 |

## 八、结论

**文档通过验证。** 仅凭 `SPIDERORB-UI复刻实现指南.md`，可以在约 1 小时内产出复刻度 90% 的可用前端页面：

- 布局比例：最大区块误差 2%，视觉重心吻合
- 色彩：平均像素色差 6.1%，主色分布一致
- 动效：11/11 全部按文档描述运行
- 健壮性：响应式 + 无障碍降级 + 零依赖离线运行

**剩余 10% 差距**主要来自：字体字形（原视频用的是设计软件里的特定像素字体，无法 100% 还原）、状态栏细节、以及原视频中部分装饰性微纹理（噪点、扫描线）未纳入文档描述。
