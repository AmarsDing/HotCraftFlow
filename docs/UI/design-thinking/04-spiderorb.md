# SPIDERORB 终端 · 设计思想

> 这套设计的精神：别让用户"操作"机器，让用户**隔着玻璃看机器超频**——整屏是一块永不休息的仪器面板，你唯一的动作是看呆。

## 1. 它在表演什么

先认清一件事：SPIDERORB 不是工具界面，是 **FUI（Fictional UI）**——它的对手不是别的仪表盘，是科幻电影里那面一闪而过的指挥室玻璃墙。观众不会点任何一个按钮（视频里根本没有光标），它要达到的效果是按下播放键 3 秒后，观众心里冒出一句话："*这玩意儿是真的在干活。*"

要演好这场戏，它回答三个问题：

- **"机器在干什么？"** → 六个 agent 各有工牌（SCT/MAP/JDG/QNT/GRD/WRT）、工号（SCOUT 43）、工序（LIFE OF A DECISION 里一条决策从 `[SCT] +19ms post found` 走到 `[MEASURED] SIGNAL +60%` 的全程流水账）。
- **"干出结果了吗？"** → 计数器永远在涨：`1,329→1,333`（labels measured today）、`10,663→10,688`（sources）、UTC 时钟真实走秒。数字涨 = 因果成立。
- **"凭什么相信？"** → 右侧 DECISION STACK 每一条决策都附"动机条码"（`SAVE ·SPDR 0.78` / `BLOCK ·SPDR 0.08`），脚注 `ONE SPIDER, 1,400 STATES, ZERO TABS OPEN`。不是"相信我"，是"自己看案卷"。

一句话：它把"AI 研究机器人"这个看不见的服务，**实体化成一台你买得起的仪器**。FUI 的成品标准只有一条——观众想伸手去摸屏幕，说明成了。

## 2. 一个主角的构图

这屏有 10+ 面板、50+ 数据点，密度全场最高，但你的眼睛从不迷路——因为构图是**一个主角 + 一圈配角**：

- **主角：THE ORB**——放射爆发网络独占中部约 38% 高度，横跨整行。它是全屏唯一的"有机体"：千丝从品红核爆射而出，金尘在左、红环在右、虚线轨道缠绕。所有旁白都为它服务：标题行 `◆ THE ORB · OBSERVABLES · 1,400 STATES · EACH ONE A SOURCE · AMPLITUDE · MODEL SCORE · 398 NEAR COLLAPSE` 是它的铭牌，左列 OBSERVABLES 五条流式 sparkline 行的末端**全部弯向它**（FOLLOWED FLOW 等波形右端上扬指向核心），底部战术带 `MEASURED OUTCOMES · 1,333 LABELS` 是它的产出证明。
- **配角的出场顺序由明度决定**：视线实测动线是 ①ORB 品红核（最高亮度+最大面积）→ ②左侧 `1,333` LED 绿字（第二亮度，点阵辉光）→ ③顶部白字大标题 `SPIDERORB // RESEARCH BOT` → ④再进入任一面板细读。前三个落点**没有一个需要你读字**——形状和光就足以完成"高科技、活着、在计数"的全部信息传递。文字从第四眼才开始工作。
- **纵向四带分工**：情报带（标题 + LIVE FEED 情报条）→ 侦察带（CORE MODEL / LIFE OF A DECISION / ENTANGLEMENT MAP 三面板）→ 主视觉带（ORB + 观测流 + DECISION STACK 决策栈）→ 部队带（SIX AGENTS 工位 + STATE BUILDER 战况 + LAST ACTIONS 战报）。从上往下是"标题→证据→奇观→结算"，一场微型汇报演出。

心法：**密度可以无限加，但主角只能有一个。** 先问"这屏的 ORB 是什么"，再让所有元素的对比度、亮度、动线都给它让路。

## 3. 关键设计决策逐条分析

### 决策 1：85:15 的霓虹配比纪律
- **做法**：近黑海军蓝底 `#0D111A` 与两级面板 `#12151E/#161922` 占约 85% 面积；霓虹强调色（绿/红/金/品红/蓝紫/青合计六种）加起来不超 15%。
- **为什么**：霓虹是盐——撒得多就是呕吐物配色，撒得少才是仪器感。85% 的黑让每一点 15% 的彩都产生"示波器波峰"的稀有感；同时大面积暗色天然降低长时间观看的疲劳。
- **何时你也该用**：一切深色界面配彩前的第一笔预算。先锁面积比，再调色相；面积比错了，什么色相都救不回来。
- **边界（demo 实证补遗）**：85:15 按**稳态**测量；告警/审批等事件态允许短暂上浮至 ~20%，事件关闭即回落——约束对象是常态，不是峰值。

### 决策 2：颜色即动作，且六个 agent 人手一色
- **做法**：决策动词有自己的色——`SAVE`=绿、`BLOCK`=红、`SKIP`=金；agent 代号有自己的色——`[JDG]` 蓝、`[QNT]` 金、`[GRD]` 红、`[MEASURED]` 绿、`[MAP]` 蓝紫。DECISION STACK 每行 = 动词色 + 代号色 + 标题白，三列语义不重叠。
- **为什么**：日志类信息流里，用户不读句子只读"色签"：一行绿色开头 = 通过了，红色 = 拦了。这是把终端的 `grep --color`植入 GUI——**给机器语言装上颜色索引**，人就能跟上机器的速度。
- **何时你也该用**：任何日志流 / 事件流 / 操作记录。规范：动词集 ≤4 个、每个动词独占一色、同一颜色永不跨语义。

### 决策 3：`◆`/`■` 符号系统 + 方括号代号，造"非民用"的文字气质
- **做法**：每个面板标题前缀 `◆`；日志行首 `[SCT]` `[ORB]` 三字母代号；分隔用 `//` 与 `·`；命令行 `spdr@Lab:~$ orb trace RUN-004228`。
- **为什么**：字体你认不出、代号你需要解码——这种"半可读性"正是军事/航天终端的魅力来源：它暗示系统有自己的行话，而行话=专业共同体。`◆` 同时是排版锚点，每个面板开头同一符号 = 视觉节拍器。
- **何时你也该用**：想要"专业黑话氛围"的产品（开发者工具、安全产品、量化终端）。注意符号集 ≤3 种、代号必须全局一致——黑话一旦穿帮（同一物两个代号）瞬间出戏。

### 决策 4：LED 点阵大计数器做唯一亮度特许
- **做法**：`1,333` 用点阵/段码风字体 + 绿色 `#53CD90` + `0 0 12px` 同色辉光，逐位翻滚（千分位逗号是独立格）。全屏只有它和 ORB 核心享受辉光。
- **为什么**：LED 质感自带"硬件仪表"联想——软件数字是打印的，LED 数字是**通电的**。辉光特许制保证它永远是第二眼（第一眼归 ORB）：若五个面板都发光，等于没有面板发光。
- **何时你也该用**：每屏选 1 个"主计数器"享受字体+辉光双特许。其余数字老老实实用普通等宽。
- **边界**：特许数按稳态计；审批/告警出现期间的事件态辉光（如审批门呼吸光）不计入配额，事件消散即熄灭。

### 决策 5：质感四件套 ≤5%，造"视频感"而非"网页感"
- **做法**：噪点 1.5–2% + 1px 扫描线 3% + 四角暗角 8–12% + 标题级文字微辉光，全部 `pointer-events:none` 罩层。
- **为什么**：干净的网页渲染太"新"，像 Excel；四层瑕疵叠上去才有 CRT/监视器的"光学证据"——观众的大脑把噪点解读为"这是被摄像头拍下来的真实屏幕"。5% 是生死线：再高一格就从氛围变成脏屏。
- **何时你也该用**：追求电影感/复古仪器感时。工业仪表盘、金融终端请保持干净——瑕疵也是一种世界观声明，别乱用。

### 决策 6：五个"徽章"当名词用（LIVE FEED / RESEARCH / GUARD PASS / SPIDER CAUGHT IT / RESEARCH MODE）
- **做法**：小胶囊徽章染语义色散布面板标题右、图表左、agent 行——红底 LIVE FEED、蓝紫 RESEARCH、绿底 GUARD PASS、品红 SPIDER CAUGHT IT、金底 RESEARCH MODE。
- **为什么**：徽章是"状态的名词化"——不说"当前处于研究模式"，直接钉一块牌子 `RESEARCH MODE`。名词化让状态可计数、可截图、可引用，还给高密度界面提供了"标点符号"：每个徽章都是一句微文案的句号。
- **何时你也该用**：状态多而杂的系统页。把形容词态（"运行中"）改名词章（`RUNNING`），密度越高收益越大。

### 决策 7：主视觉用"放射爆发"而非"均匀点阵"
- **做法**：ORB 的视觉公式 = 爆发核 + 200–400 条辐射细丝 + 丝上微粒 + 6–8 个品红卫星 hub（各带虚线轨道）+ 1–2 圈金色大虚环 + 左侧静星尘；细丝只做 ±3% 正弦呼吸，**不做 O(n²) 连线**。
- **为什么**：均匀随机点阵 = 壁纸；有核心、有丝、有轨道 = 天体。爆发式构图自带能量方向（一切从核心来），契合"观测站"叙事。不做全连接是性能与观感的双赢：千丝呼吸比连线动画更像"引力场"，且 Canvas 开销可控。
- **何时你也该用**：网络主视觉（关系图、威胁情报、知识图谱）。公式：一个核 + 放射 + 卫星 + 静背景（星尘不连线）= 便宜的高级感。

### 决策 8：情报带（ticker）与徽章**静态**，只让"数据"动
- **做法**：356 帧里 LIVE FEED 跑马灯位移 ≈0、SPIDER-ON 徽章亮度恒定；动的只有计数器、日志、光点、网络呼吸。
- **为什么**：这是最反直觉也最专业的一笔。市面 90% 的模仿者会让跑马灯滚起来——一滚就露馅：仪表仪器不播广告，**滚动字幕是门户网站的语言，不是仪器的语言**。FUI 的"真"恰恰来自克制：该静的坚决静。
- **何时你也该用**：永远。先把动效预算全部砍到零，再只为"数据本身的变化"逐项加回——你会惊讶发现要加的其实很少。

### 决策 9：六 agent 用"像素图标 + 工号 + 状态"三张牌人格化
- **做法**：每只 agent 一块小方砖：像素风线框图标（雷达/三角/柱状/曲线/八边形/记事本）+ 三字母代号 + 全名 + 大数字工号（CARTOGRAPHER `1,250`）+ 一行状态（`SIGNAL IN & OUT`），GRD 砖用红、WRT 砖用金，底色各行其是。
- **为什么**：和 GrokBot 的彩色生物同理——AI 团队需要"花名册"。区别在语气：GrokBot 是活物（青蛙、星形），SPIDERORB 是**兵种**（雷达兵、测绘兵、军法官）——像素图标强化"复古军工"世界观。
- **何时你也该用**：多 agent 系统展示。图标风格 = 产品世界观的外延：圆萌=消费级，像素=极客军工，线条=企业级。

### 决策 10：黑话数据自洽（unit 一致性）
- **做法**：`1,400 STATES` 同时出现在 ORB 铭牌、页脚、`1,400 STATES` 徽章；`1,333` 是 labels measured today，与 ORB 下方 `1,333 LABELS`、SIX AGENTS 的 `DECISIONS OUT · 1,333 LABELS` 三处呼应；UTC 时钟与 iOS 状态栏时间不同（仪器用 UTC，人用本地）。
- **为什么**：观众说不清哪里真，但能感觉到"没有哪处假"。同一指标多位置复现且数值一致，是"这背后真有数据库"的最强暗示；穿帮一次（两处对不上），幻象即崩塌。
- **何时你也该用**：一切数据演示/概念视频。建一个"单一事实表"驱动全部 UI，绝不手填数字。

## 4. 微动态哲学：全部运动都是"数据在吃饲料"

这段 5.9s / 356 帧视频**零转场、零运镜、零 hover**，却在体感上"动得停不下来"。它的动效是一门减法艺术：

- **动的都是值的代谢**：`1,329→1,333`、`10,663→10,688`、`72%→70%`——每个数字都在以自己的速率进食、消化、排出。六秒后你回头看，每一个面板都不是原来的面板，但**没有任何一个像素做过"位移动画"**。
- **节奏分三档，永不合拍**：走秒级（UTC 钟）、呼吸级（ORB 细丝 ±3%、曲线光点巡航）、事件级（日志推入、DECISION STACK 换牌、计数器跳格，间隔泊松随机 600–1200ms）。三档错相叠加产生"混沌的活感"——若所有动画同周期，一秒就读出机器心跳，假象立破。
- **光点永远在路上**：曲线上的青色光点、流线末端的白色光点、轨道上的绕行微粒——同一个 `getPointAtLength` 技法复用五次。FUI 的"电在板子里跑"的感觉，九成功劳在这几个旅行者身上。
- **静止是声明**：LIVE FEED 不动、徽章不动、布局不动——这些静止不是没做，是**做了不动的决定**。仪器的权威感恰恰建立在"有些东西永远不会晃"上。

学它最难的不是技法，是纪律：每加一个动效前先问——"这是数据变了，还是我想让它热闹？" 后者请删掉。

## 5. 学完带走的三大招

1. **一个主角 + 亮度特许制。** 每屏只许一个"奇观"（ORB/大图/大表）+ 一个"主计数器"享受辉光和面积特许，其余全部配角化。密度不怕高，怕的是十个元素同时喊"看我"——观众的视线会死机。
2. **用"行话三件套"造世界观：符号前缀（◆）+ 方括号代号（[GRD]）+ 名词态徽章（GUARD PASS）。** 成本几乎为零，但要求军事级一致性：代号表写死在代码里，全界面引用，永不即兴造词。氛围 = 细节的零穿帮。
3. **动效预算归零启动，只赎回"数据代谢"。** 转场、跑马灯、入场动画全部不给；只为值的变化、日志的推入、光点的巡航付费。判断标准：把眼睛眯起看 3 秒，如果你看到的是"数字在换"而不是"东西在飞"，就对了。
