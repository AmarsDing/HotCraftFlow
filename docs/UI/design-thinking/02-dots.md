# DOTS 三态：图谱 · Node Map · 作战室 · 设计思想

> 导语：这三段视频卖的不是功能，是一份新的人机劳动合同——"机器干活、你签字"；密度是它的公章，金色是你的签名栏。

## 1. 三个界面，一个世界观

DOTS 生态的三段演绎在叙事同一个命题：AI 已经是劳动力，而劳动力需要管理。三段视频各自回答其中一个问题：

- **图谱（kiosa jev-cascade-02）回答"机器此刻在想什么"**。一次 agent 执行被摊成 20 个节点、350 条边的活体标本，右下角常亮一行脚注 `LLM writes · Jev decides · code acts`——LLM 负责写、Jev 负责判、代码负责动手，三方权责白纸黑字。
- **Node Map 回答"机器每天替我做了什么"**。编辑部特写 `Five dots. One launch team.`，肩题 `ONE JOB EACH. ONE MEMORY. YOU SIGN OFF.`，五个 dot 各有工牌、日程和产出，右下角永远留一块 `YOU · REVIEW + SIGN OFF` 的签收区。
- **作战室（DOTS + GPT-6.1）回答"机器替我赚的钱我怎么敢认"**。8 张 Agent 卡里压轴的一张叫 APPROVAL，主数值不写数字，直接写 `YOU`，脚注 `ENTRIES REQUIRE YOUR APPROVAL`。

三种粒度——单次推理、一天分工、一笔钱——但都把"人类批准"做成视觉系统里地位最高的元素。这就是贯穿的世界观。

视觉性格上三者截然不同，各自服务一种情绪。图谱的"绿毛球"是**实验室感**：近黑绿底 + 白色噪边雾，像显微镜下的神经组织，情绪是"可观测"——你不需要读懂每根线，只需要看见它确实有人盯着。Node Map 是**编辑部感**：衬线大标题、红色肩题、整齐的栏格和 "08:00 CET calendar brief" 这类日程，情绪是"可信赖的同事"。作战室是**军事感**：16px 实心红框把整块媒体围成一间"舱"，情绪是"指挥与后果"——有钱（$2,810.00）、有敌人（SKEPTIC 拦下 2 条回收假消息）、有命令链（大屏下沿 `SOURCES → OBJECTIONS → SIZE → YOUR APPROVAL`）。绿毛球让你"看见智能"，编辑部让你"习惯同事"，红作战室让你"敢下命令"——一个世界观的三个情绪入口。

## 2. "密度即智力"的信仰从哪来

先看那个著名的比例：NODES 20，EDGES 350，边是节点的 17.5 倍。这不是数据需要，是**表态需要**。如果目的是让你读懂拓扑，20 节点配 40 条边够了；配 350 条，就是要它"读不完"。这套设计的逻辑是：观众对"智能"的想象是非语言的，一团读不完的线网比一张能看懂的流程图更能传达"这里面有东西在思考"。机房玻璃墙、交易所行情墙同理——信息的不可尽读性本身就是信息：系统很大，而且在工作。

脚注和微标签同理。GRAPH COST 面板里 `median 245 ms`、`held at gate 37`、`input / M tokens $0.042`，没有观众会逐个核对，但它们的存在意味着"每一个数字都能被追查"。密度的功能不是阅读，是**担保**。Node Map 把同一逻辑用在组织架构上：DOTCORE 列表连 `APPS 4,000+` 和 "+ 3,996 more" 都写给你看，潜台词是"这个同事的履历你可以一直往下翻"。

那密度什么时候是灾难？当用户需要在这一屏做一个具体操作时。而 DOTS 自己对此心知肚明：全盘皆密，唯独"等你签字"的地方被提纯出来——Node Map 里 `waiting on you` 单独染金，作战室里 AWAIT USER 是全场唯一实体按钮。**密度是背景，决策点必须是最空的那个元素。** 这才是密度信仰的真正用法。

## 3. 关键设计决策逐条分析

### 决策 1：毛球分四层画——雾 → 网 → 粗边主干 → 霓虹点链
- **做法**：t0.5 帧里 350 条边先以发丝白噪铺一层"雾"；局部加粗成浅白"网"勾出主干；gate → human·publish 之间单独拉一束高亮黄电缆；最上层是沿边奔跑的亮绿点链。FLOW 视图（f_09.72）里雾层整体调青，变成一条发光的"决策河"。
- **为什么**：四层各管一个焦距——远看是一团活着的雾（智能在呼吸），中看有主干道（信息有方向），近看有点链（数据正在流）。只画一层都会塌：只有雾=杂乱，只有主干=普通流程图，只有点链=装饰。
- **何时你也该用**：任何"复杂度本身就是卖点"的图——微服务拓扑、数据管道、组织关系。要点是各层权重递减但全程同时可见。

### 决策 2：语义色 = 状态机，全片零例外
- **做法**：gate ≥ 0.85 面板和 Choice · next_worker 的卡头是红色（拦截与决策），review 卡里 hold 一行单独翻红，human · publish 描边是金色（轮到人），LLM · writer 是蓝色（模型供能），常态节点青绿。HEAT 视图（f_13.61）更极端：整卡灌色，completed_work 99% 全红，LLM 3% 全青，负载直接映射绿→琥珀→红。
- **为什么**：高密屏里用户没时间读字，颜色必须是先行通道。零例外是信用的来源——一旦某个"红"只是装饰，用户就再也无法整屏读红了。
- **何时你也该用**：状态维度超过 3 种的仪表盘。先写死映射表，再画界面，顺序不能反。

### 决策 3：每行数据自带一条填充条，兼作条形图
- **做法**：Score · urgency 卡里 `low 0.388 / medium 0.458 / high 0.648 / critical 0.764`，行底压一条同语义色填充条，条宽≈数值。Node Map 的 progress 条干脆整条染成角色色（38% 黄、100% 品红）。
- **为什么**：省掉整张图表。数字给精确值，条给直觉比较，零坐标轴成本换来"可扫读的条形图阵列"。注意他们从不给条画轨道框——条直接躺在行底，像文字排版的一部分。
- **何时你也该用**：一切表格型面板。这是"无图表化"的关键手法。

### 决策 4：所有面板共用一副四段式骨架——微标签 → 主数值 → 辅条 → 脚注
- **做法**：GRAPH COST 是范本——顶行 `GRAPH COST` + live 脉冲点，中段指标行，48px 绿色大计数器 `$0.29`，jev vs LLM 对比条，脚注那句口号。作战室 Agent 卡同构：`SCOUT / SOURCES KEPT / 3 / 76 / 细条 / SOURCE LINK ATTACHED`。
- **为什么**：骨架统一 = 学习成本归零，第二张卡起用户只看数值不看结构。脚注是"态度位"——放口号、放署名（`kiosa · @thegreatest_sv`），让面板有作者人格。
- **何时你也该用**：同屏面板 ≥4 个就必须统一骨架。脚注最容易被砍，别砍——那是密度里唯一允许"说话"的地方。

### 决策 5：阶段字幕 = 编号 + 4px 竖条，把录屏变成发布日志
- **做法**：左下常驻阶段字幕，如 `05 ESCALATE / human owns the post`：编号 + 大写等宽标题 + 黄色小字副标，左侧一条 4px 语义色竖条（03 绿、04 红、05 琥珀、VIEW 系青、06 绿）。字幕本身只有 150ms 交叉淡变，绝不滑入滑出。
- **为什么**：它把一段功能演示升格成有章节的叙事——任何时刻落地的观众都知道自己在第几幕，竖条颜色还预告这一幕的情绪（红=卡住了，绿=放行）。
- **何时你也该用**：时长 >15s 的产品录屏。成本极低，叙事收益极大。

### 决策 6：人类批准点用"金"，并在多处同时点亮
- **做法**：Node Map 16:49 帧，SALES LEAD 遇到越权请求的瞬间整行五处同时转金：角色卡 `needs you`、RULE 卡勾选 `needs you`、状态胶囊 `waiting on you`、顶部汇总条 `waiting on you 1`、YOU 队列新增一条未勾的 `@you-sales reply to client…waiting`。作战室的 AWAIT_USER 则是金底实体钮 + 呼吸微光，钉在复盘面板头部全程不走。
- **为什么**：观测型产品里用户的唯一动作就是"介入"，所以"该介入了"必须是全屏最高对比信号；金色不与红绿争语义，天生读作"待定、等你"。
- **何时你也该用**：审批与告警确认。同一状态在 ≥3 个位置同时显化（原位、汇总条、待办队列）——单点提示在密屏里必然被淹。

### 决策 7：让 X 帖子 chrome 真的压上去
- **做法**：f_19.44–f_26.25 里，作战室是 X 详情页内嵌的视频；帖子头部卡（头像 + Logics + 关注按钮）用约 -126px 的负 margin 叠在红色容器下缘之上，盖住左下 POSITION REPLAY 面板的一角，半透明近黑底让底下的 K 线隐约透出。
- **为什么**：真实感第一定律是"让 UI 吃亏"。完美避开 = 广告摆拍；被压住、被截断 = 它真的存在于世界里被人刷到。录屏 25.5s 时拍摄者甚至拉下了 iOS 控制中心（f_24.30），这种"事故"被保留，反而成了最强的真实背书。
- **何时你也该用**：演示物料与 sizzle 视频。刻意让一层界面侵入另一层的安全区，比喊一百句 "real product" 有力。

### 决策 8：转场全部硬切，0ms
- **做法**：18.5s 处图谱 → X 帖子页无任何过渡；GRAPH / FLOW / HEAT 视图切换也只给 150ms 交叉淡变。
- **为什么**：观测界面的权威感来自"系统不表演"。你拨示波器档位的时候没有淡入淡出——过场动画是叙事的，硬切是仪器的。省下的动效预算全部拨给数据流动。
- **何时你也该用**：工具、仪表盘、监控类界面。营销页别这么干，会显得没做完——硬切是"我在工作"的姿态，不是通用审美。

### 决策 9：大计数器等宽 + tabular-nums，且先快后慢
- **做法**：`$0.29`（图谱）、`$2,810.00`（作战室）用 40–64px 特粗等宽数字，跳动时布局纹丝不动；作战室余额从 $73 起步，经 $271、$1,896 一路 ease-out 冲到 $2,810 后定格。
- **为什么**：数字是这类界面的主角，主角不能在台上晃。先快后慢是叙事曲线——用几秒演完"三天从 $63 到 $2,810"的弧线，减速段让观众来得及消化终点那个数字。匀速 = 表格，ease-out = 故事。
- **何时你也该用**：一切 KPI 计数动画。tabular-nums 是底线，缓动曲线是剧本。

### 决策 10：dot 生物用"形状 × 颜色"双编码，跨三片复用
- **做法**：黄色戴眼镜团子 = RESEARCHER，蓝色 = BUILDER，粉色爱心 = LAUNCH LEAD，绿青蛙 = SALES，橙红团子 = CREATOR——Node Map 的角色卡、连接线（虚线弧颜色跟随角色）、作战室的工位吉祥物、DOTS 旗帜上的五颗点，全是同一套编码。
- **为什么**：双编码让色盲、远视、小屏三种退化场景下仍可辨认；"生物"而非图标，是给 AI 同事上人格——你会让青蛙加班，不会让 icon-04 加班。人格化不是卖萌，是降低"管理 AI"的心理门槛。
- **何时你也该用**：多 agent 系统的角色设计。形状与颜色永远不要单独使用。

### 决策 11：连线走"走廊"，不踩内容
- **做法**：Node Map 中 SOURCES 列表 → DOTCORE 总线 → 五张角色卡，所有点状贝塞尔被约束在列间空白带里汇流、分道（t5.53 帧蓝紫线与金色线各行其道）；图谱的边再乱也不压面板文字。作战室则用顶部 4×2 芯片带 + 底部双面板排，把 3D 场景夹在中间 740px 的"视窗"里。
- **为什么**：密而不脏的全部秘密是"走线与排版互不侵犯"。走廊是预先为混乱留好的基础设施，像城市规划里的综合管廊——先管廊、后入住。
- **何时你也该用**：一切带连线的布局（DAG、架构图、组织图）。先把走廊画出来，再让内容进来。

## 4. 动态叙事：三段视频分别怎么"讲故事"

**图谱用"阶段字幕"推进**，是一段六幕剧：03 CHOICE→WRITE 抛问题，04 GATE HOLDS 起冲突（confidence 0.71 < 0.85 被拦），05 ESCALATE 转交人类，VIEW·FLOW / VIEW·HEAT（`where decisions travel` / `load per node`）是两段炫技间奏，落到 06 CODE ACTS 时——字幕、成本计数器、questions.py 代码面板三轨同时走到结论 `10 000 decisions = $0.42`。叙事靠"章节"硬切，不靠运镜。

**Node Map 用"时间轴"讲**：`DAY 1 · 24H IN 20S`，顶部时钟 04:26 → 10:20 → 16:49 → 21:04，底部 THE DAY 时间轴上彩色菱形逐个落位，连线颜色随活跃的 dot 换班（金色研究 → 蓝紫构建 → 品红发布）。故事高潮是 16:49 的 SALES `needs you` 全行转金，结尾是 21:04 时 YOU 队列里攒下的 4 个绿勾（06:45 / 12:09 / 17:08 / 18:56 四条待签收产出）——一天结束，机器干完的活排队等你签字，肩题 `YOU SIGN OFF.` 就此兑现。脚注还补一刀：`some steps never leave your hands: a password change is one`。

**作战室用"自动播放的财经快报"讲**：它干脆不要字幕，余额计数器 $73 → $2,810 就是进度条，K 线逐根 reveal，星座网络每 4.2 秒重绘一轮，六个 dot 在工位间不断换岗（对比 f_19.44 与 f_22.36，位置全变了）——让你以为在直播，其实只是回放。证据链星座不时在不同位置闪现（卡片区、账户带、大屏、复盘图轮着来），像解说员的激光笔。

三者的共同交互观：**hover 语义极弱，激活态才是主要反馈**。光标在画面里基本是观众（全片唯一一次出手是 t9.24 拖了一下 write 卡，tooltip 报 `23 wires · dragging`）；真正的语言是"激活"——卡片描边点亮、状态胶囊变色、金门发光、点链流过。hover 邀请探索，激活汇报状态；对一个"你大部分时间在旁观看"的界面，后者才是母语。

## 5. 学完带走的三大招

1. **把密度当立场，不当负担。** 先想清楚这一屏是给人操作还是给人信任。给人信任的屏幕，密度就是演技——四层毛球、17.5 倍边、翻不完的 DOTCORE 清单，都是。但同一屏里，决策点必须密中取空：金色、留白、一颗实体按钮。
2. **让颜色当状态机，让面板当骨架复读机。** 语义色映射写死并零例外，四段式面板骨架定死并全屏复用。做完这两件事，高密度下界面依然"读得动"——因为用户读的不是字，是你的纪律。
3. **为"轮到人"设计全片最贵的视觉资产。** DOTS 三态的所有词汇最后都收敛到同一个瞬间：`human owns the post`、`waiting on you`、`AWAIT USER`、`YOU`。好的 AI 产品界面不是把自动化演到最满，而是把"人类签字"那一帧做成全屏最有仪式感的画面——因为那是用户存在的理由。
