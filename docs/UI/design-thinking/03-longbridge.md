# 长桥金融终端 · 设计思想

> 这套设计的精神：用户敢把真金白银押在这块屏幕上，所以每一个像素都在回答同一句话——"你可以相信我"。美观不是目标，是信任的副产品。

## 1. 金融 UI 的第一性问题：信任

普通产品的问题是"用户爱不爱用"，金融终端的问题是"用户敢不敢用"。敢不敢，由无数个小承诺兑现累积而成，这套设计把承诺拆成了四类看得见的证据：

- **精度承诺：等宽数字。** `51723.010` 这种三位小数的指数值（帧01 Index 卡）、-0.54% 的涨跌幅，全部 `tabular-nums` 锁宽。行情每 100ms 刷一次，如果数字宽度在跳动，整个表格都在抖，用户潜意识里读出的是"这台机器不太稳"。数字可以变，站位不能变——这是专业终端和普通后台的分水岭。
- **语境承诺：地毯式标注。** 时区（`Trading 10/12 09:50:36 EDT`，帧06 右栏）、币种（`Currency: USD`，帧08 桑基图图例）、市场（`US NASDAQ`/`US NYSE` 前缀）、复权状态（`Split-Adj. ⇄`）、账户（`Demo A/C(1757)`）。每一条数据都自带"出身证明"，用户永远不用猜"这是哪个时区的价格"。
- **在线承诺：底部状态栏。** 全产品唯一一条 30px 状态栏（z02）：DOW/NASDAQ/S&P500 三指数实时值 + `2026/10/12 21:50:14` 服务器时间戳 + 绿色连接点。它在告诉用户两件事：数据流活着、你看到的不是缓存。30px 换一份安心，是全局性价比最高的一行。
- **克制承诺：动效不抢戏。** 实时 tick 绝不进出场动画，只做 600ms 背景闪烁；视图转场则用从容的 900ms——数据区快而静，容器区慢而稳。一条规律：**凡是用户要读的，动它等于撒谎；凡是用户在等的，动它等于安慰。**

## 2. 极端密度下的秩序

1135×690 的窗口里塞着 8-12 个信息模块（帧06 个股页：左自选列 + K 线 + 成交量 + 右报价/订单簿/成交明细 + 底交易面板），主力字号压到 12px、角标 10px。这种密度下不乱，靠的是三件兵器：

1. **四档背景明度代替投影与边框。** 应用底 `#18191D` → 面板 `#1E2026`（亮 4%）→ 浮层 `#22242A` → 输入/代码区 `#141517`。不用阴影堆叠层级，用明度台阶"默背"层级——你的余光扫过就知道哪块浮在上、哪块沉在底。投影在浅色主题里是高级感，在深色高密度里是噪声。
2. **发丝线做账簿。** 分隔一律 1px `rgba(255,255,255,.06)`，表格走斑马纹 + 连续行，不用卡片块。卡片是陈列品语气，连续行是账簿语气——账簿让人相信每一条都被登记在册。
3. **颜色只做两件事：方向和差异。** 青=涨、玫红=跌是唯一的全局语义；其余颜色全部退场（文字三档灰 `#E6E8EB / #9AA0A6 / #62666E`）。帧04 的九宫格自选股，一屏 200+ 个数字，你扫一眼只记得住红色绿色——这正是设计要的效果：**可一扫性（scannability）高于可阅读性。**

密度管理的本质不是"塞更多"，而是给眼睛铺一条高速公路：等宽列对齐、右对齐数字、左对齐文字、图标全部 18px 以下，人的视线不需要"找"，只需要"扫"。

## 3. 关键设计决策逐条分析

### 决策 1：涨跌语义色与交互色双轨
- **做法**：数据方向用青涨（`#35C8A8`）玫红跌（`#F0568C`）；交互主色另设一枚青绿 `#0CA890`——Buy 按钮、活动 Tab 填充、AI 入口、链接全部用它。
- **为什么**：如果"点它"和"它在涨"共用一个颜色，界面上每个上涨数字都像一个按钮，每秒数百个假按钮在闪。把"数据语言"和"操作语言"分到两条轨道上，用户大脑可以并行处理：眼睛收数据，手找操作。
- **何时你也该用**：任何语义色已经名花有主的领域（涨跌、状态告警、健康度）。再给交互留一个"第五色"，宁滥勿缺。

### 决策 2：闪烁只闪背景，600ms 淡出，文字永远站稳
- **做法**：价格跳动时整行背景刷一层方向色（青/玫红），600ms 淡出；数字本身始终高对比、tabular-nums、不闪不跳。
- **为什么**：闪文字 = 在你阅读的瞬间夺走文本；闪背景 = 用余光通知你"这行变了"，正文始终可读。600ms 是"被注意到"和"不打扰"之间的甜点：再短被忽略，再长变成告警。
- **何时你也该用**：一切高频刷新的流式数据（行情、监控、日志）。记住口诀：提示变化靠底色，传达内容靠文字，两者永不互借。

### 决策 3：四档明度台阶，禁用阴影层级
- **做法**：底→面板→浮层→输入，四档明度各差 4% 左右；只有悬浮卡/Toast/命令面板才动用真正的投影（`0 8px 24px rgba(0,0,0,.45)`）。
- **为什么**：深色主题里投影几乎不可见，强行用只会得到一团黑雾；明度台阶是无光环境里的透视法。而稀缺的投影被严格保留给"真的浮起来"的东西（z03 hover 卡、帧19 命令面板），投影一旦出现就一定是模态级事件——克制让投影重新变成信号。
- **何时你也该用**：一切深色高密度工具。先定明度阶梯，再规定"全产品只有三种元素允许投影"。

### 决策 4：选中态三副面孔，但全产品只此三副
- **做法**：筛选级用**描边胶囊**（帧02 的 `S&P 500 Index`、帧01 的 DOW：青描边 + 青字、不填充）；主导航级用**填充胶囊**（`Heatmap`、`Option Chain`：实心青底白字）；行内选中用**2px 侧竖条 + 底色**（左图标栏、自选列当前行）。
- **为什么**：三副面孔对应三个层级——"你在过滤数据"、"你在这个视图"、"你在这个对象"。层级被视觉语法固定下来，用户不需要学习每个页面的局部约定。
- **何时你也该用**：先列出你产品里所有"选中"的语义级（全局/视图/过滤/对象），每级绑定一种且仅一种视觉形式，然后写进 lint 规则。

### 决策 5：视图转场用形变 + 运动模糊，900ms 的从容
- **做法**：切换视图时旧视图 `scale(0.96) + blur(6px) + 淡出`，新视图 `scale(1.04) + blur + 淡入`，900ms ease-out-expo——帧05 捕捉到的正中间帧全屏重度模糊。
- **为什么**：Blur 是关键。纯缩放像幻灯片，加了模糊就像相机重新对焦——用户的眼睛被允许"虚掉"0.9 秒，新旧信息密度才不会在视网膜上打架。时长也够诚实：一个金融终端在装载大量数据，900ms 的"过场"比 300ms 的"闪烁完成"更可信。
- **何时你也该用**：信息密度差异巨大的整页切换（列表↔图表↔编辑器）。低密度产品请自觉减半时长。

### 决策 6：AI 抽屉来时，主内容物理"退后"
- **做法**：AI 抽屉滑入的同时（帧10），主内容区 `scale(.97) + brightness(.85)`，800ms 同步；关闭时弹回。
- **为什么**：不用遮罩（遮罩=切断），用缩小+压暗（=退后一步的舞台）。透视学告诉用户：行情还在原地等你，只是现在是 AI 的聚光灯时间。上下文没被夺走，只是被降权——这点差别就是"打断"和"陪伴"的差别。
- **何时你也该用**：一切侧拉式辅助面板（审计、AI、详情抽屉）。前景上台 100%，背景退到 97%，这 3% 的纵深就是空间感本身。

### 决策 7：热力图用离散 9 档色阶，图例即筛选器
- **做法**：涨跌幅按绝对值分 9 档（`#78183C` 深玫红到 `#D7165E` 亮玫红对 `#0C7A6A` 深青到 `#2BC4A8` 亮青），0 档灰；顶部同一组颜色做成可点 chips（帧02 顶部 `<-3% -3% … >+3%`），点 chip 即筛出该档股票。
- **为什么**：连续渐变好看但不可操作——你无法回答"把跌超 3% 的都给我"。离散档让颜色有了刻度，刻度才可以变成按钮。图例、筛选、编码三合一，少一个组件，多一层一致性：tile 的颜色和 chip 的颜色是同一份数据。实测 NVDA -0.63% 与 AVGO -0.41% 落同档同色（`#781942`≈`#771A42`），证明映射是"档位优先、档内微调"，而非逐值渐变。
- **何时你也该用**：当颜色承担定量含义且用户需要按颜色行动（筛选、告警）。装饰性渐变请随意；功能性着色必须落档。

### 决策 8：分裂压力条表达对抗
- **做法**：期权页 `Call 124.20K ←—— 71:29 ——→ Put 50.65K`（帧14/z09）：一条 8px 分裂条，左青右玫红，中间嵌到期倒计时；报价栏 `Bid 57.14% | Ask 42.86%` 同理（帧06）。
- **为什么**：多空、买卖本质是拔河。两个数字需要你心算对比，一条拔河绳把对比变成姿态——绳子歪向哪边，力量就在哪边，扫一眼即得。中间还能白赚一个位置放倒计时这种第二信息。
- **何时你也该用**：任何二值对抗（通过率 vs 否决、供给 vs 需求、错误 vs 成功占比）。注意只限"两部分构成整体"的场景，三段以上请改用堆叠条。

### 决策 9：大面积语义填充只赏给 Buy/Sell
- **做法**：全产品几乎不见实心色块，唯独底部交易面板的 `Buy` 是实心青胶囊、`Sell` 实心玫红（帧06 底部）；Tab 填充也用同一枚青。
- **为什么**：色彩的面积就是声量。终端里 95% 的颜色应该用于"读"，只有 5% 配许用于"吼"——而这 5% 必须留给产生真金白银后果的动作。用户在 200 个数字中余光定位下单键，靠的就是这块唯一的实心色。
- **何时你也该用**：高危/关键 CTA 定义法——全产品只挑 1-2 个动作允许实心填充，其余一律幽灵或描边。

### 决策 10：▲▼ 字符三角，而非图标或 +/- 号
- **做法**：Monitor 流、自选列、期权链全部用字符级 `▲▼`（帧01 的 `▲ SpaceX Large buy`），着色跟随语义。
- **为什么**：字符三角随字体走、随字号缩放、绘制零成本、屏幕阅读器可读，44KB 的字体文件里躺着不花一分请求费。在高频追加流里（Monitor 每秒来几行），每个 DOM 节点的成本都在乘电流，字符是最便宜的方向符号。
- **何时你也该用**：高频渲染列表里的方向/趋势标识。图标系统留给"需要品牌感"的地方，数据流内部用字符。

### 决策 11：事件徽章用文本缩写，不用图标
- **做法**：`52-week low`、`Large buy`、`E`（财报）、`D`（分红，帧06 K 线轴下方圆徽章）、到期日条上的 `w` 上标（周度期权，帧14）。
- **为什么**：`52-week low` 这种事件没有通用图标可画，硬画就是抽象画猜谜。文本徽章 11px 灰底，密度高、语义自解释、本地化成本低。E/D 单字母圆徽章则是传统金融终端（Bloomberg/TradingView）的族群暗号，懂行用户一见如故。
- **何时你也该用**：领域有成熟缩写惯例时，尊重惯例胜过发明图标；没有惯例时，短文本 > 生造图标。

### 决策 12：时间锚 + 连接点沉入状态栏
- **做法**：底部 30px 固定条（z02）：头像、市场切换、三指数实时值、`2026/10/12 21:50:14` 时钟、绿点，全局每页都在。
- **为什么**：金融判断的第一步是"这是什么时候的数据"。把时钟和连接状态压进全局骨架，等于给每一屏数据盖上时间戳骑缝章——任何截图都能自证时效，这对合规、复盘、扯皮都是基础设施级的好设计。
- **何时你也该用**：实时数据产品。时钟、延迟、连接健康度三件套永驻底部，是一份不花钱的信任保险。

## 4. AI 功能如何"长"在传统终端里

这套产品的 AI（助手、财报解读、AI 选股）没有任何"外挂感"，方法值得逐条抄：

- **同一套令牌，一个不差的继承。** AI 面板用的背景/字号/圆角/间距与终端本体完全一致——帧13 里 AI 返回的选股表（# | Ticker | Company | Mkt Cap | 1M% | YTD% | Price），列对齐、tabular-nums、涨跌着色和原生列表毫无二致。AI 说的"语言"就是终端的语言。
- **只允许一个签名元素。** AI 唯一的视觉特权是全屏欢迎页标题下那道 **粉→橙→青三色渐变下划线**（帧12 `Hello, may I help you?`）和输入框的 ✦ 火花图标——一个渐变签名宣告"这里是 AI 区"，用完即止。给新功能立户口的正确方式：一枚签名，而不是一整套皮肤。
- **形态是抽屉和放大，不是跳转。** 右抽屉 → 全屏用共享布局形变（帧10→帧12），消息流位置连续；上下文（K 线）始终在场或被优雅降权（scale .97）。AI 是"过来帮忙的同事"，不是"另一个系统"。
- **过程透明化。** 思考时 `✦ Nebulizing… 0s` 秒表 + 随机俏皮文案（t68p02），调用工具时列出 Agent 步骤条（`Screener indicators · 1s` + 脉冲点，帧13）——等待被游戏化，过程可被审计。再配一条钉死在每次回复底部的灰字免责声明（`This content is AI-generated…`，帧11），诚实是金融 AI 的入场券而不是免责声明。
- **结果即组件。** AI 回答不是纯文本，而是内嵌的行情卡、45 行着色数据表、迷你图——回答完直接可以盯着它做决策。**AI 的产出物规格 = 原生组件库**，这是"长在里面"的技术含义。

## 5. 学完带走的三大招

1. **先划颜色的"轨道"，再开始设计。** 语义色（数据方向）、交互色（可点动作）、品牌签名（渐变）分三条轨道，立下"全产品仅 1-2 个动作允许实心"的面积配额。颜色工程学是金融 UI 的第一课，漂亮调色盘是最后一课。
2. **密度不是靠堆，是靠层级语法。** 四档明度台阶 + 1px 账簿线 +等宽数字铁律 + 三种绑定层级的选中态，足以养活 12px 字号下的信息海。当你的密集界面开始乱，先查层级语法是否唯一，再查字号。
3. **新功能入住老产品：继承令牌、签一个名、形态连续。** 别给它新皮肤（那是外挂），给它一枚签名元素（渐变线、一枚图标）就够；"抽屉→全屏"的连续形变胜过一切路由跳转。功能是新的，信任是旧的——延续信任比宣示新意值钱得多。
