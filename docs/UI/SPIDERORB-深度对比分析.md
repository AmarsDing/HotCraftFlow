# SPIDERORB — 视频原稿 vs 前端 Demo 深度细节对比分析

> **方法**：将原视频首帧（内容区 y450–2150）与复刻 Demo 全页截图（内容区 0–2134）按内容高度归一化，逐区块生成上下并排对比图，并对关键区域做全分辨率放大复查；动效部分用相位相关（phase correlation）与逐帧 diff 做定量核验。
> **关于证据图**：对比过程产生的 11 组逐区块并排图与原图放大图（原存于 `verify/deep/`）已在归档清理中移除，复核时对照本目录 `SPIDERORB-源视频.mp4` 逐帧暂停即可；Demo 现为 `spiderorb-demo.html`。
> **结论**：宏观布局/配色/节奏已达标（见《SPIDERORB-复刻验证报告》），但本次放大比对发现 **3 处组件级误判 + 6 处细节缺失**，已全部回填至《SPIDERORB-UI复刻实现指南 v2》。

### 区块 8 · 主视觉行 —— ⚠ 发现 3 处组件级误判（本次最重要发现）

**误判 1：左列不是"四个径向仪表"，而是"五条流式 sparkline 行（Stream Rows）"**

初版分析（`crops/11_gauges.png` 时代）把波浪线误读为圆弧。全分辨率放大（`x_orig_streams.png`）确认每行结构为：

```
▎FOLLOWED FLOW            5        [JDG]  ┐
▎FOLLOWED POSTS · LA                       │ 波浪 sparkline（同色，
▎~~~~~~~~~~~~~~~~~~~~~~~~~~~●              │ 末端白色光点，线条向
                                            ┘ 右上扬起汇入 ORB 网络）
```

| 行 | 标签 | 值（色） | boxed tag | 流线色 |
|---|---|---|---|---|
| 1 | FOLLOWED FLOW / FOLLOWED POSTS · LA | 5（绿） | `[JDG]` 绿 | 绿 `#53CD90` |
| 2 | BOT SHARE / LIKES FROM BOT FARMS | 28.6%（品红） | `[MAP]` 品红 | 品红 `#D8425D` |
| 3 | HYPE RISK / FROM REPLY HYPERS | 44%（金） | `[MAP]` 金 | 金 `#FFDD83` |
| 4 | REPLY DEPTH / REAL REPLIES IN | 7.14%（蓝紫） | `[BOT]` 蓝 | 蓝紫 `#A2B3DF` |
| 5 | TOPIC PHASE / ABOVE OPEN 24H | 10.0%（白） | `[SCT]` 白 | 白 `#E5E3E7` |

结构要点：左侧 3px 彩色竖条 + 主标签（白粗体）+ 暗色副标签 + 右对齐彩色数值 + boxed 代号 chip + 横贯整行的波浪 sparkline（带淡色面积填充）+ 末端白色光点（沿波形流动）。**五条流线的右端向上扬起、汇入中央 ORB 网络**——这就是原指南说的"流线流入网络"的真实形态。

**误判 2：THE ORB 不是"均匀随机粒子网络"，而是"放射爆发 + 卫星 hub"结构**

全分辨率放大（`x_orig_orb.png`）确认其解剖结构：

1. **中央爆发核**：位于画面中心偏上，数百条白色细丝（filaments）从核心向外辐射成扇形/蒲公英状，丝上串着白色微粒；
2. **卫星 hub**：约 6–8 个品红发光节点分布在爆发核左/下/右周，每个 hub 外围有**白色虚线同心轨道环**（2–3 圈，dashed ellipse），环上有绕行微粒；
3. **金色虚线大环**：左下区域有 1–2 个大型金色虚线圆轨道；
4. **背景星尘**：左侧散布金色小点（不连线）；
5. **浮动标签**：核心上方有金色斜角 boxed 贴纸 `ad for a course`；
6. **整体动态**：细丝随呼吸节奏摆动，微粒沿丝/轨道缓慢移动（非布朗漂移）。

与初版"~180 粒子布朗漂移 + 距离 <90px 连线"的描述**偏差较大**——Demo 的视觉密度和结构感明显不足（对比图 `08_orb_net.png` 可直观看出：原图是"焰火"，Demo 是"星图"）。v2 已重写该组件规格与代码。

原视频每行是一个**带完整边框的盒子**（`x_orig_sigout.png` / `08_orb_decision.png`）：

## 二、全局质感差异（视频 vs 网页的"最后一公里"）

| 维度 | 原视频 | Demo | 建议 |
|---|---|---|---|
| 噪点/颗粒 | 全屏细颗粒噪点（胶片感） | 无 | 叠加 1-2% 透明度的噪点层（SVG feTurbulence 或平铺 PNG） |
| 扫描线 | 极淡的全屏水平扫描线 | 仅计数器有 | 全屏 `repeating-linear-gradient` 0.03 透明度 |
| 暗角 | 四边轻微 vignette | 无 | 一层 radial-gradient 罩 |
| 文字辉光 | 亮色文字普遍带 2-4px 柔光 | 仅计数器/光点有 | 对 `#E5E3E7` 标题级文字加 `text-shadow: 0 0 6px` |
| 画质 | H.264 压缩致色块略灰、边缘略糊 | 锐利纯净 | 属载体差异，不必模拟 |

> 注意：噪点/扫描线/vignette 也可能部分来自录屏压缩。实现时做到"若有若无"（透明度 ≤5%）即可，过度会像廉价滤镜。
