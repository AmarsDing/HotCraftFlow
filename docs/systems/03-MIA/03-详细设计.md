## 2. 核心算法

### 2.1 实体链接（`biz/mia/entity_link.go`）

```go
func (u *Linker) Link(ctx context.Context, e contract.Entity) ([]AssetHit, error) {
    // 1. 归一化：去空格、大小写、全半角
    // 2. 精确匹配 entity_name，再匹配 entity_alias
    // 3. 未命中 → 模糊匹配（相似度 ≥0.85），命中则降 confidence × 0.8
    // 4. 过滤 confidence < 0.6（低于此值不进 MIA，见需求 §10）
}
```

**输出**：`[]AssetHit{symbol, asset_class, direction_bias, confidence, rule_id}`

> 映射未命中时返回**空**，`impact_score` 记为 0 并标记 `no_mapping`，**不得**强行匹配。

### 2.2 情感与方向（`biz/mia/sentiment.go`）

```go
type SentimentEngine interface {
    Name() string                 // "finbert" | "llm"
    Supports(lang string, isMacro bool) bool
    Classify(ctx context.Context, in SentimentInput) (SentimentResult, error)
}

type SentimentResult struct {
    Label string      // positive / neutral / negative
    Score float64     // -1 ~ 1
}
```

**引擎选择策略**

```
if lang == "en" && !isMacro        → FinBERT（自托管，快且专业）
if lang == "zh" || isMacro         → LLM（云优先，Ollama 降级）
if FinBERT 不可用                   → 降级 LLM
if LLM 也不可用                     → Label = "unknown"，Score = 0   🔴 禁止猜测
```

**FinBERT 分数换算**

```
score = P(positive) - P(negative)          # ∈ [-1, 1]
label = score >  0.15 ? "positive"
      : score < -0.15 ? "negative"
      : "neutral"
```

### 2.3 事件聚类（`biz/mia/event_cluster.go`）

```
新 IntelItem X:
  1. 取近 24h 的 EventCard 候选
  2. 相似度 = 0.5·实体重合度(Jaccard) + 0.3·标题语义余弦 + 0.2·时间接近度
  3. 相似度 ≥0.82 → 并入（source_intel_ids 追加，source_count++）
  4. 否则 → 新建 EventCard
```

> **source_count 是 `source_weight` 的输入**——多源转载说明事件更重要，但也可能是同一稿件的多次转载，需按**不同域名**去重计数。

### 2.4 影响面评分（`biz/mia/impact_scorer.go`）

```
sentiment_factor = |sentiment_score|                       # 0–1
                   # unknown 时为 0（不猜）

source_weight    = min(1, 0.4 + 0.15 × log2(distinct_domain_count))
                   # 1 个源 ≈0.4，2 个 ≈0.55，4 个 ≈0.7，8 个 ≈0.85
                   # 再乘以信源可信度基准表（官方/央行/交易所 = 1.0，自媒体 = 0.6）

relevance        = mean(top3 AssetHit.confidence)
                   # 实体映射置信度的均值；无映射为 0

decay            = exp( -age_hours / ttl_hours )
                   # ttl 默认：股票/宏观 24h，加密 12h；可由叙事表覆盖（6h）

impact_score     = 100 × sentiment_factor × source_weight × relevance × decay

direction        = sentiment_score > 0  ? bullish
                 : sentiment_score < 0  ? bearish
                 : neutral
```

**输出必须含四因子明细**（契约 `impact.factors`）：

```go
type ImpactFactors struct {
    Sentiment    float64
    SourceWeight float64
    Relevance    float64
    Decay        float64
}
```

**TTL 过期处理**：`expires_at` 到期的卡片**不删除**（审计需要），但：
- 列表默认过滤 `expires_at > now`
- 推送只发未过期卡片
- 校准任务仍可访问

### 2.5 跨资产传导（`biz/mia/transmission.go`）

```go
type TransmissionRule struct {
    ID          string
    Trigger     TriggerSpec     // {Asset, Direction, MinMovePct}
    ToAsset     string
    ToDirection Direction
    Confidence  float64         // 🔴 必填
    Note        string          // 🔴 必填
}
```

**初始规则示例**

| 触发 | → 传导至 | 方向 | confidence | 说明 |
|------|---------|------|-----------|------|
| `DXY` 上涨 ≥0.5% | 新兴市场股指 | bearish | 0.50 | 资金外流假设 |
| `DXY` 上涨 ≥0.5% | 黄金 | bearish | 0.55 | 计价效应 |
| `DXY` 上涨 ≥0.5% | `BTC/USDT` | bearish | 0.45 | 风险偏好假设 |
| 美债 10Y 上行 ≥10bp | 成长股/科技 | bearish | 0.50 | 折现率假设 |
| 央行降息 | 本地股指 | bullish | 0.60 | 流动性假设 |
| 主要经济体降息 | `BTC/USDT` | bullish | 0.40 | 弱相关，仅作参考 |

> 🔴 **全部规则标注 `confidence` 且 ≤0.6**。这不是保守，而是诚实——跨资产传导本就是假设，标 0.9 是自欺欺人。

**匹配逻辑**

```
对每条 ImpactCard 的 affected：
  查 TransmissionRule 中 Trigger.Asset ∈ affected.symbols 且方向匹配
  → 生成传导项：{symbol, direction, confidence: rule.Confidence × parent.Confidence,
                 path: parent.path + ["→ " + rule.Note], is_transmission: true}
```

### 2.6 影响路径生成（`biz/mia/path_explainer.go`）

```
直接映射：  path = [entity_name, "→ " + asset_class + " " + symbol, "（映射依据：" + notes + "）"]
传导项：    path = parent.path + ["→ " + rule.Note]
```

**模板化 + 映射表 `notes` 拼接**，不做自由生成（避免 LLM 编造因果链）。

### 2.7 行情校验（`biz/mia/verifier.go`，P2）

```
校验时点：T+1h / T+24h / T+72h
actual_move = (close(T+n) - close(T)) / close(T)
hit = (direction=bullish ∧ actual_move >  threshold)
   ∨ (direction=bearish ∧ actual_move < -threshold)      threshold 默认 0.3%
```

**校准报告**（按 `rule_id` / `entity` 维度）：

| 维度 | 统计 |
|------|------|
| 样本量 | 校验完成的卡片数 |
| 方向命中率 | `hit / total` |
| 时间窗口 | 起止日期 |
| 市场状态 | 区间内主要指数涨跌（**必须**注明） |

> 🔴 **报告页固定提示**：「本统计为规则校准参考，**不代表预测准确率**；样本量 <30 时结论不具统计意义。」

## 5. 错误处理

| 错误码 | 场景 | 处置 |
|--------|------|------|
| `MIA_MAPPING_NOT_FOUND` | 实体无映射 | 返回空 affected，**不强行匹配** |
| `MIA_SENTIMENT_UNAVAILABLE` | 情感引擎全不可用 | 返回 `unknown` + `engine=none`，**禁止猜测** |
| `MIA_DISCLAIMER_EMPTY` 🔴 | 免责声明为空 | **拒绝落库与推送**（硬失败） |
| `MIA_PATH_EMPTY` 🔴 | affected 项 path 为空 | **拒绝落库**（硬失败） |
| `MIA_CONFIDENCE_INVALID` 🔴 | confidence 越界或缺失 | **拒绝落库**（硬失败） |
| `MIA_QUOTE_READ_FAIL` | 行情拉取失败 | 跳过校验，**不影响**影响分产出 |
| `MIA_OPENBB_LICENSE_UNVERIFIED` | OpenBB 许可证未复核 | **拒绝接入**（阻断式） |
| `MIA_LLM_CAP_EXCEEDED` | 云 LLM 超日调用上限 | 熔断，转 Ollama；Ollama 不可用则 `unknown` |
| `MIA_TRADING_BLOCKED` | 检测到交易类调用 | 立即拒绝 + **critical 告警** |
