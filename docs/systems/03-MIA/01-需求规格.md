## 1. 需求澄清（关键边界）🔴

> **这一节决定了整个子系统的范围。理解偏差会导致完全做错的东西。**

「情报收集」在本项目中**不只是**媒体热点，还包括：

| # | 维度 | 内容 |
|---|------|------|
| 1 | **采集主题** | 时政人物、商界精英、行业发展、科技突破、新兴技术 |
| 2 | **分析目标** | 判断该消息的**影响面**——对股市某类/某只股票的积极或负面影响、货币市场、经济走势，以及数字货币 |
| 3 | **市场范围** | **全球**各大股市 + **数字货币** |

### 1.1 明确排除

> **安全侦察类 OSINT 属于不同问题域**，擅长用户名/子域/攻击面枚举，**不覆盖**「媒体热点 → 市场影响面」。**不纳入**本系统，仅作边界对照：

`Sherlock`（用户名探测）· `Maigret` · `SpiderFoot` · `theHarvester`（域名/邮箱枚举）· `Amass`（子域枚举）· `OpenCTI`（威胁情报）· `reNgine` · `IntelOwl`（攻击面测绘）

### 1.2 明确不做 🔴

| 不做 | 原因 |
|------|------|
| **不产出投资建议** | 全部输出为研究/监测辅助，**强制**免责声明 |
| **不启用交易能力** | 行情依赖**只读**（ccxt 交易接口一律不启用），NFR-19③ |
| **不承诺因果** | 跨资产传导是**规则假设 + 相关推断**，必须标 `confidence` |
| **不承诺准确率** | 行情校验只用于校准，**不承诺预测准确** |
| **不整篇再分发新闻正文** | 新闻有版权，适合内部分析 |
| **默认不对外发布** | 待决策 Q2；V1 建议仅内部 + 强制免责声明 |

## 2. 用户故事

| # | 作为… | 我希望… | 以便… |
|---|------|--------|-------|
| US-1 | 分析师 | 看到一条重大消息可能影响哪些板块/个股/币种 | 快速定位关注对象 |

## 3. 开源成熟度分层（决定「哪些必须自建」）

| 层 | 开源成熟度 | 代表 | 结论 |
|----|-----------|------|------|
| 媒体/RSS 采集与聚合 | **较高** | news-please、Crawl4AI | 可 Depend |
| 英文财经情感分类 | **较高** | FinBERT | 可 Depend（自托管推理） |
| 全球行情与加密行情接入 | **较高** | OpenBB、ccxt | 可 Depend（**只读**） |
| **事件 → 标的映射 / 影响路径** | **低，需自建** | — | **必须自建** |
| **跨资产传导与因果校准** | **低，需自建** | — | **必须自建** |

> **一句话**：开源擅长「把新闻捞进来并打情感/事件标签」；「这条消息拖累哪只股票、利好哪个板块/币种」这一层，**几乎都要靠规则库 + LLM + 行业知识自建**。

### 3.1 必须自建的五件事

| # | 事项 | 说明 |
|---|------|------|
| 1 | **人物 / 政策 → 标的** | 领导人表态、制裁、降息 → 指数 / 行业 ETF / 汇率 / 避险资产 |
| 2 | **行业 / 科技突破 → 产业链个股** | 例：HBM 突破 → 存储 → 设备 → 封测 |
| 3 | **加密叙事 → 币种** | ETF、监管、公链升级、稳定币；CryptoPanic 的币标签**仍不够** |
| 4 | **跨资产传导规则** | 只能当**假设**，须标置信度，**不得**当因果结论 |
| 5 | **去重与事件聚类** | 多源转载合并成一条「事件卡」**再**算影响 |

## 4. 分析流水线

```
IntelItem（C_market 类）/ TrendSeries
  ↓
① 实体链接（人物/机构/政策/技术 → 市场标的）
  ↓
② 情感与方向判断（FinBERT 英文 / LLM 中文宏观）
  ↓
③ 事件聚类 → EventCard（多源转载合并）
  ↓
④ 影响面评分（情感 × 源权重 × 相关性 × 时效 TTL 衰减）
  ↓
⑤ 跨资产传导规则（强美元 ↔ 新兴市场股/黄金/BTC，标注置信度）
  ↓
⑥ ImpactCard（事件 + 影响路径 + 关联标的 + 置信度）
  ↓
⑦ 行情校验（OpenBB 股 / ccxt 币，只读）→ 事后校准规则权重
```

## 5. 功能需求（FR-MIA-\*）

| ID | 名称 | 描述 | 验收标准 | 优先级 |
|----|------|------|----------|--------|
| **FR-MIA-01** | 实体→标的映射表 | 表 A：`entity_name / entity_type / asset_class / symbol / direction_bias / confidence / notes` | 可增删改查；导入导出 CSV；命中可追溯 | **P0** |
| **FR-MIA-02** | 叙事→币种映射表 | 表 B：`narrative / keywords / coins / default_sentiment_hint / ttl_hours` | 同上；TTL 生效 | **P0** |
| **FR-MIA-03** | 财经情感分类 | 英文标题+摘要跑 **FinBERT** → 正/中/负 | 可自托管推理；结果可查 | **P1** |
| **FR-MIA-04** | 中文/宏观 LLM 摘要 | 中文与宏观时政用 LLM 一句话摘要 + 方向 | 云 LLM + Ollama 降级通路可用 | **P1** |
| **FR-MIA-05** | 事件聚类与事件卡 | 多源转载合并为一条事件卡 | 可人工拆分/合并；保留全部来源指针 | **P0** |
| **FR-MIA-06** | 影响面评分 | 分数 = 情感 × 源权重 × 相关性 × TTL 衰减 | **分数带 TTL（6–24h 可配）**；各因子可见；输出偏多/偏空/中性 | **P0** |
| **FR-MIA-07** | 行情接入 | OpenBB（股/指数/宏观）+ ccxt（币）**只读** | 可拉 OHLCV；只读无需交易密钥 | **P1** |
| **FR-MIA-08** | 跨资产传导规则 | 规则标注 `confidence`，输出时一并展示 | **禁止**把假设当因果；置信度必显 | **P1** |
| **FR-MIA-09** | 影响路径解释 | 文本化解释「为什么影响该标的」 | 每结论附路径与依据 | **P1** |
| **FR-MIA-10** | 双调度 | 股市：交易时段密集 + 盘后摘要；加密：固定短周期（5–15 分钟） | 两套调度独立可配 | **P2** |
| **FR-MIA-11** | 行情校验与校准 | 事后对照实际涨跌，校准规则权重 | 可出校准报告；**不承诺准确率** | **P2** |
| **FR-MIA-12** | 高影响推送 | 高分条目推送（Webhook / 企业微信等） | 含影响路径与免责声明 | **P1** |

**P0 共 4 条**（01/02/05/06），构成「MIA 可用」最小集。

## 6. 非功能需求（NFR）

| ID | 名称 | 要求 |
|----|------|------|
| **NFR-MIA-01** | 免责声明 🔴 | 所有 `ImpactCard.disclaimer` **非空校验**，为空则不允许落库与推送 |
| **NFR-MIA-02** | 只读约束 🔴 | 行情依赖**只启用只读**；交易/下单/撤单能力在配置层硬关闭 |
| **NFR-MIA-03** | 置信度必显 🔴 | 每条 `affected` 项必须带 `confidence`；跨资产传导结论必须标「假设非因果」 |
| **NFR-MIA-04** | 影响路径必带 🔴 | 每条 `affected` 项必须有非空 `path`；无 path 的结论视为违约 |
| **NFR-MIA-05** | 开源复核 | 遵守 NFR-19 四项：SPDX 实测 / 数据源 ToS / 只读 / 免责声明 |
| **NFR-MIA-06** | 双调度隔离 | 股市与加密调度独立；一方故障不影响另一方 |
| **NFR-MIA-07** | 时区纪律 | 统一存 UTC，展示 Asia/Shanghai；跨市事件按事件时间对齐 |
| **NFR-MIA-08** | 降级 | FinBERT 不可用时降级为 LLM；LLM 也不可用则**不产出方向结论**（不猜） |
| **NFR-MIA-09** | 成本 | 云 LLM 调用总量帽（硬上限，超限熔断）；优先本地推理 |
| **NFR-MIA-10** | 审计 | 每条 ImpactCard 保留规则版本与权重快照，可复算 |

## 7. 加密 7×24 架构注意点

| # | 要点 | 说明 |
|---|------|------|
| 1 | **双调度** | 股市：交易时段密集 + 盘后摘要；加密：固定短周期（5–15 分钟） |
| 2 | **去重与叙事合并** | 加密圈标题党多，**避免单条噪声直接映射成方向信号** |
| 3 | **时区** | 统一存 UTC，展示 Asia/Shanghai；跨市事件按事件时间对齐 |
| 4 | **影响衰减** | 分数带 TTL（6–24 小时），避免旧利好长期占排行榜 |

## 9. 验收标准（子系统级）

| # | 验收项 | 判据 |
|---|-------|------|
| 1 | 映射表可用 | 表 A ≥200 条实体映射；表 B ≥30 条叙事映射；CSV 导入导出可用 |
| 2 | 事件聚类 | 抽样 50 条同源转载，合并为单事件卡正确率 ≥90% |
| 3 | 情感分类 | FinBERT 英文财经标题三分类准确率 ≥75%（公开基准水平） |
| 4 | 影响分可解释 | 随机 20 张 ImpactCard，全部含四因子取值 + 影响路径 + 置信度 |
| 5 | **免责声明 100%** 🔴 | 全部输出含 `disclaimer`，为空则系统拒绝落库（自动化校验） |
| 6 | 只读约束 | 代码审计确认无交易路径；ccxt 配置层无 API 交易密钥 |
| 7 | 双调度 | 股市与加密调度独立配置，停一方另一方照常 |
| 8 | 契约合规 | `ImpactCard` 100% 通过 JSON Schema |

## 11. 诚实声明 🔴

1. **影响面非因果**：MIA 输出是**规则分 + 相关推断**，**不是**稳定因果。跨资产传导只能当假设并标置信度。
2. **不承诺准确率**：行情校验用于校准规则权重，**不是**准确率承诺。任何「系统命中率 XX%」的表述若未注明样本与口径，都是不诚实的。
3. **中文财经情感弱于英文**：FinBERT 是英文模型；中文/宏观依赖 LLM，质量与成本都需实测。本需求**不承诺**中文效果。
4. **OpenBB 未核实**：主仓库名与许可证本轮未能确认，引入前**必须**复核。
5. **映射表是长期工程**：FR-MIA-01/02 的映射表需要持续维护，初始 200 条只是「可用」起点，**不是**「够用」终点。
6. **合规等级最高**：本子系统的输出一旦被误读为投资建议，风险量级远高于内容分发。**免责声明、置信度、影响路径三项是硬性校验，不是可选装饰**。
