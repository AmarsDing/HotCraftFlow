## 7. 风险与砍单顺序

### 7.1 风险登记

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| **Q2 未拍板** | 中 | **高**（设计无法定稿） | Phase 2 启动前必须拍板；默认「仅内部」可先行 |
| 映射表数据准备不足 | **高** | **高**（无映射 = 无结论） | 提前到 Phase 1 后期启动；CSV 批量导入；分析师参与 |
| OpenBB 许可证风险 | 中 | 中 | 引入前强制复核；备选直连其他数据源 |
| 中文情感质量不佳 | 中 | 中 | LLM + 人工复核；**不承诺**准确率 |
| 加密叙事噪声导致误判 | **高** | 中 | 事件聚类前置，多源合并才打分 |
| FinBERT 部署（GPU 依赖） | 中 | 中 | CPU 可跑但慢；评估是否需要 GPU 资源 |
| 云 LLM 成本 | 中 | 中 | 日调用上限 + Ollama 降级 |

### 7.2 砍单顺序（延期时**自上而下**砍）

```
1. FR-MIA-11 行情校验与校准（移至 Phase 3）
2. FR-MIA-10 双调度（降为仅加密 7×24，股市走统一周期）
3. FR-MIA-07 行情接入（降为仅 ccxt 加密，股市延后）
4. FR-MIA-04 中文/宏观 LLM（降为仅英文 FinBERT，中文人工补）
5. FR-MIA-08 跨资产传导（降为 3 条核心规则）
6. FR-MIA-09 影响路径（降为映射表 notes 直出，不做模板拼接）
────────── 以下为 🔴 不可砍 ──────────
   FR-MIA-01/02 映射表（无映射则系统无意义）
   FR-MIA-05 事件聚类（多源不合并会导致噪声放大）
   FR-MIA-06 影响面评分（核心）
   免责声明 / path / confidence 三项硬校验
   只读约束（NFR-19③）
```

> 🔴 **合规项不参与砍单**。免责声明、置信度、影响路径、只读约束是法务底线，任何排期压力都不得移除。
