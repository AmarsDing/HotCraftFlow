## 7. 风险与砍单顺序

### 7.1 风险登记

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| newsnow/RSSHub 部署延期 | 中 | 高（阻塞 M2） | **提前到 M0 完成**，不等 W2 |
| 平台反爬升级导致 crawl 路失效 | 中 | 中 | 优先热榜/API/RSS，crawl 仅补充 |
| 语义去重阈值难调 | 高 | 中 | 预留人工拆分 + 样本记录，按周迭代 |
| 实体抽取中文效果不佳 | 中 | 中 | 先用规则兜底，LLM 增强后置 |
| 证据快照撑爆磁盘 | 低 | 中 | 90 天留存 + 自动清理 |

### 7.2 砍单顺序（延期时**自上而下**砍）

```
1. FR-INT-17 情报简报（P2）
2. FR-INT-08 实体抽取（降为规则版）
3. FR-INT-09 情报分类（降为关键词规则）
4. FR-INT-14 检索（降为简单列表 + 过滤）
5. FR-INT-10 可加工性（降为固定阈值）
────────── 以下为 🔴 不可砍 ──────────
   FR-INT-12 合规闸门
   FR-INT-11 取证快照
   FR-INT-06/07 归一化与去重
   FR-INT-02 热榜采集
```

> **铁律**：合规闸门、取证链、审批门、默认私密四项在任何排期压力下**都不得移除**（PRD §11.1）。

## 8. 验收门禁

进入下一阶段前必须通过：

| 门禁 | 检查 |
|------|------|
| **契约门禁** | `IntelItem` 100% 通过 JSON Schema；向后兼容测试通过 |
| **合规门禁** | 代码审计确认闸门无旁路；100% 条目经闸门 |
| **证据门禁** | 随机 20 条证据包均可导出且字段完整 |
| **稳定门禁** | 连续 7 日采集成功率 ≥95% |
| **许可门禁** | `NOTICE` 齐备；无 GPL/AGPL 代码进主仓 |
| **可观测门禁** | 八项指标全部上报；三类告警规则生效 |
