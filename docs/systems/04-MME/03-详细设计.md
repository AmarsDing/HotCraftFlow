## 2. 核心算法

### 2.1 素材去重（FR-MIX-07）

```go
func (u *AssetUsecase) Ingest(ctx context.Context, p IngestParam) (*Asset, error) {
    fp := fingerprint(p.LocalPath)              // 采样前 64MB + 文件大小 + 时长
    if exist, err := u.repo.ByFingerprint(ctx, fp); err == nil {
        exist.RefCount++                         // 引用计数 +1
        u.repo.Save(ctx, exist)
        os.Remove(p.LocalPath)                   // 删除重复下载的文件
        return exist, nil
    }
    return u.repo.Create(ctx, &Asset{Fingerprint: fp, RefCount: 1, ...})
}

// 回收：ref_count == 0 且 created_at 超过留存期 → 删除文件与记录
```

### 2.2 缓存 Key 设计（FR-MIX-02）

```
cache_key = sha256( asset_id + "|" + kind + "|" + engine + "|" +
                    engine_version + "|" + prompt_version + "|" + lang )
```

| kind | 额外纳入 key 的因素 |
|------|-------------------|
| `transcript` | asr_engine、lang |
| `chapters` / `report` / `keyframes` | prompt_version、user_intent 哈希 |
| `reframed` | 切点哈希 + 画幅 |

> **user_intent 纳入 key 的原因**：不同意图会产出不同的章节与报告，缓存复用会导致结果错误。

### 2.3 矩阵展开（FR-MIX-01）

```go
type ExpandRequest struct {
    TaskID        string
    ContentVersions []ContentVersion   // B 维度：来自高光候选
    Aspects       []Aspect             // A 维度：默认 [9:16, 1:1, 16:9]
    Hooks         []Hook               // C 维度：默认 ≥2
    TemplateID    string
}

func (u *MatrixExpand) Expand(ctx context.Context, req ExpandRequest) (*VariantSet, error) {
    // 笛卡尔积，但**不渲染**
    for _, cv := range req.ContentVersions {
        for _, asp := range req.Aspects {
            for _, hk := range req.Hooks {
                v := &Variant{
                    ContentVersion: cv.Label,
                    Aspect:         asp,
                    HookID:         hk.ID,
                    EDLRef:         cv.EDLRef,     // 切点在 B 维度确定
                    Selected:       true,
                    RenderState:    pending,
                }
            }
        }
    }
    // 生成 VariantSet（纯元数据，秒级完成）
}
```

**规模保护** 🔴

```
max_variants_per_set = 60（可配）
超出时拒绝展开并提示：「组合数 N 超过上限，请减少内容版本或 Hook 数量」
```

> **理由**：渲染是算力密集操作，无上限的笛卡尔积会瞬间打满队列。

### 2.4 平台文案差异化（FR-MIX-04）

**四套语气基线**

| 平台 | 语气 | 长度 | 特点 |
|------|------|------|------|
| `douyin` | 口语、强钩子、情绪化 | 标题 ≤30 字 | 前 3 秒定生死 |
| `xiaohongshu` | 种草体、emoji、标签多 | 标题 ≤20 字 | 重标签与封面 |
| `bilibili` | 信息密度高、分点 | 标题 ≤80 字 | 重信息量 |
| `youtube_shorts` | 简洁英文、关键词前置 | ≤100 字符 | SEO 友好 |

**实现**：LLM 生成 + 平台 prompt 模板。**同一 content_version 的四套文案共享分析结果**（缓存复用）。

**校验**：
- 各平台长度上限校验，超限截断并提示
- 与源文案的差异化检查（见 §2.5）

### 2.5 差异化度检查（FR-MIX-05）🔴

```go
type DiffChecker interface {
    // 返回两两相似度的最小值与该对变体
    Check(ctx context.Context, setID string) (DiffResult, error)
}

type DiffResult struct {
    MinPairSimilarity float64
    Warn              bool
    Pairs             []PairSimilarity   // {A, B, visual, hook, copy, audio}
}
```

| 维度 | 算法 | 告警阈值 |
|------|------|---------|
| **视觉** | 抽 N 帧 → pHash → 汉明距离 → 序列平均相似度 | ≥0.90 |
| **Hook** | 前 3s 视频帧 pHash + 音频指纹（可选） | ≥0.85 |
| **文案** | 标题 + 简介 SimHash 汉明距离 | ≥0.92 |
| **综合** | `max(visual, hook, copy)` | ≥0.90 → `warn=true` |

**处置**（设计权衡，见概要设计 §6.2）：

```
warn=true → VariantSet.diff_warn=true
         → 审核台**高亮**该对变体 + 提示「建议改 Hook / 封面 / 开头」
         → **不阻断**送审（人工决策）
```

### 2.6 渲染自检（QC）

| 检查项 | 判据 | 失败处理 |
|--------|------|---------|
| **边界** `boundary_ok` | 时长在 [min, max]；无黑帧开头/结尾；分辨率符合画幅 | `qc_score` 扣分，严重则 `false` |
| **字幕** `subtitle_ok` | 字幕在安全区内；无句中硬切；SRT 与视频时长匹配 | `false` |
| **音画同步** | 音轨存在且时长匹配 | 扣分 |
| **manifest** | manifest.json 存在且字段完整 | `false` |
| **文件完整性** | 可 ffprobe 解析，无损坏 | `false` |

🔴 **硬门禁**：`boundary_ok=false` 或 `subtitle_ok=false` 的变体**不得**进入审批门（契约 §4 已约定）。

### 2.7 渲染命令基线（FFmpeg）

**9:16 reframing（无 GPU，中心 + 主体偏移）**

```bash
ffmpeg -i input.mp4 \
  -vf "crop=ih*9/16:ih,scale=1080:1920:flags=lanczos" \
  -c:v libx264 -crf 23 -preset medium \
  -c:a aac -b:a 128k \
  -t <duration> output_916.mp4
```

> ⚠️ **诚实标注**：无 GPU 时只能做中心/规则裁切，**不是**智能主体追踪。若需主体追踪须引入额外模型（不进 MVP）。

**字幕烧录（simple 档）**

```bash
ffmpeg -i input.mp4 \
  -vf "subtitles=sub.srt:force_style='FontName=Noto Sans CJK SC,FontSize=16,MarginV=380,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,Outline=2'" \
  -c:a copy output_sub.mp4
```

> `MarginV=380` 对应 9:16 底部安全区（概要设计 §5.2）。

**封面抽帧**

```bash
ffmpeg -ss <t> -i input.mp4 -vframes 1 -q:v 2 cover.jpg
```

**manifest.json 结构**

```json
{
  "variant_id": "v_01J...",

  "duration_sec": 58.4,
```

```proto
syntax = "proto3";
package media.v1.mme;

option go_package = "framework/api/gen/go/media/v1/mme;mmev1";

import "google/api/annotations.proto";

enum Aspect { ASPECT_UNSPECIFIED = 0; ASPECT_9_16 = 1; ASPECT_1_1 = 2; ASPECT_16_9 = 3; }
enum VariantSetState {
  VARIANT_SET_STATE_UNSPECIFIED = 0;
  VARIANT_SET_PLANNED = 1;
  VARIANT_SET_RENDERING = 2;
  VARIANT_SET_REVIEW = 3;
  VARIANT_SET_APPROVED = 4;
  VARIANT_SET_REJECTED = 5;
}

message PlatformCopy { string title = 1; string desc = 2; repeated string tags = 3; }

message Variant {
  string id = 1;
  string content_version = 2;
  Aspect aspect = 3;
  string hook_id = 4;
  double duration_sec = 5;
  string video_path = 6;
  string cover_path = 7;
  map<string, PlatformCopy> copy = 8;      // key 必须与 MAP 平台键一致
  bool selected = 9;

}

message DiffResult {
  double min_pair_similarity = 1;
  bool warn = 2;
  repeated PairSimilarity pairs = 3;
}

message PairSimilarity {
  string variant_a = 1; string variant_b = 2;
  double visual = 3; double hook = 4; double copy = 5;

  string task_id = 2;

  }
  rpc Render(RenderRequest) returns (RenderResponse) {

  }
  rpc Review(ReviewRequest) returns (VariantSet) {
    option (google.api.http) = { post: "/api/v1/media/mme/variant-sets/{id}/review" body: "*" };
  }
```

## 5. 错误处理

| 错误码 | 场景 | 处置 |
|--------|------|------|
| `MME_DOWNLOAD_FAIL` | yt-dlp 下载失败 | 提示 Cookie 配置；可读错误（风控/需登录/404） |
| `MME_ASR_FAIL` | 转写失败 | 保留中间产物；可换引擎重试 |
| `MME_LLM_UNAVAILABLE` | 云 LLM 不可用 | 降级 Ollama；仍失败则任务暂停（**不猜**) |
| `MME_EXPAND_TOO_LARGE` | 组合数超上限 | 拒绝展开 + 提示减少维度 |
| `MME_RENDER_FAIL` | 渲染失败 | 保留中间产物；可重试；记录 ffmpeg stderr |
| `MME_QC_FAILED` 🔴 | 质检不通过 | 标记 `qc=false`，**阻断**送审 |
| `MME_DIFF_WARN` | 差异化度过低 | **不阻断**，告警 + 审核台高亮 |
| `MME_CACHE_MISS` | 缓存未命中（非错误） | 正常重跑并记录，供命中率指标统计 |
| `MME_STORAGE_FULL` | 存储超限 | 阻断新渲染 + 提示清理 |
| `MME_JIANYING_VERSION_MISMATCH` | 剪映草稿版本不兼容 | 提示 `[待测]`；建议改用 ZIP 导出 |
